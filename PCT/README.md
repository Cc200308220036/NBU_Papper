Git 起点为 `2e4edb32`，分支由 `dev/jev-select` 创建。此信息仅定位起点，不代表后续 HEAD 永久不变，也不替代任务报告。

## 2. 本工程目标与论文定位

在**统一缓冲容量 1、轴对齐直立 0/90 度、相同公开信息和公共物理合同**下，将 PCT 学习策略接入现有完整订单链路，与 Jev 无经验策略及确定性几何基线比较。

首选设计是复用公共候选池，由 PCT 网络选择候选，公共订单循环维护真实状态、监测、提交与恢复。该版本暂称 **PCT-adapted（公共候选池适配版）**，不能称为原论文算法的无修改复现。

统一容量 1 后只研究当前位置选择，不再研究缓冲内跨箱选择。其结论不能直接替代容量 3 下长期选箱与经验增强的主实验结论。单箱仍可有多个候选位置，不等于所有步骤都自动执行。

本工程第一阶段目标是明确合同并验证工程可行性，不预设 PCT 或 Jev 必须获胜，不保证所有订单都能完整装入。工程接通、原生复现、迁移有效和研究收益分别验收。

## 6. PCT 输入、动作和权重注意事项

1. **输入语义**：逐字段核对已放节点、叶节点、下一箱、padding、mask 与归一化。张量形状正确不代表语义正确。选择器只消费公开状态和公共候选，不得注入未来箱体、见证、终态或监测预评。
2. **候选编码**：每个有效叶节点绑定唯一公共候选 ID 及精确姿态；网络输出直接查表返回原候选，不用“最近位置”替换。候选截断、去重、顺序及随机种子显式冻结，不能按模型或稳定性成绩选候选。
3. **坐标**：明确托盘中心坐标与 PCT 原生角点坐标的转换，包括原点平移、中心/角点转换、单位及 z 底面高度；做往返核对。转换不移动真实动作，不依赖隐式落箱修正。
4. **姿态**：只允许直立 0/90 度，不启用 PCT 的六朝向模式；对相等边长和对称箱不能仅靠尺寸猜动作，要保留显式姿态映射。
5. **质量与密度**：如使用 PCT 密度路径，质量、体积与单位必须一致；密度不是顶部承载上限。保持相同物理量的无损转换，不通过取整尺寸或随意缩放质量改变难度。
6. **节点上限**：已放节点与候选节点容量必须覆盖冻结实验范围；超限显式失败或使用预先验收的扩展，不静默丢弃箱体、支撑关系或状态。
7. **承载信息**：原网络不等于已经建模本项目的 `stackable` 和顶部承载。只靠公共检查的版本应明确其输入局限；新增承载特征并训练属于另一版本，不能仍称原权重直接推理。
8. **原生环境隔离**：不调用 PCT 原生 `step()` 维护第二份真状态，不将其虚拟稳定性过滤接到公共候选之前。确需原生复现时，另立独立实验范围与报告。
9. **权重**：官方 README 提供预训练链接，但本工程尚未验证下载、加载及适用性。原生候选上的权重迁移到公共候选后可能分布失配；随机初始化不能冒充已训练基线。
10. **依赖**：PCT 原件使用较旧的 Gym/PyTorch 接口。先核对环境兼容，后续依赖安装或权重下载按具体任务授权执行，不污染现有主线环境。

## 7. 公共监测、提交与恢复合同

顺序固定：**公共候选 → 独立选择 → 保存选择 → 独立状态副本监测 → 保存结果 → 提交或终止**。

- 沿用当前已验收精确位置算法，核对 `pct_exact_pose_network_v3` 的实际路由及配置身份；不因根 AGENTS 保留历史 v2 说明而回退旧根入口。
- 监测只评估选定精确动作。不预过滤、不向模型提供 PCT 反力或稳定性标签，失稳后不改选第二候选。
- `STABLE` 后由公共 `commit_physical` 复核并提交一次；不因 PCT 网络推荐而绕过边界、碰撞、支撑、stackable 或包装承载检查。
- `UNSTABLE` 记录预测静态失稳并停单；`UNASSESSABLE` 与 `ERROR` 分别停单。失败箱不放入、不移出缓冲、不增加已装件数/体积/质量。
- 单候选自动执行与所有选择方法使用同一监测入口。正式监测对照必须显式启用唯一开关，禁止静默关闭或回退算法。
- 面积分载账本与静态反力分开，不互相回写。只能报告预测静态失稳，不能解释为真实坍塌概率。
- 复用 `SELECTED → MONITORED → COMMITTED/TERMINATED` 语义。已存选择不重推理覆盖，已存监测不重算覆盖，已提交动作不重复提交。
- 恢复绑定原始/派生数据、源码、依赖、策略、权重、特征、候选和监测身份；变化时拒绝恢复，不重签历史摘要。
- 未来涉及远程 Jev 对照时，继续保留未知发送状态，禁止隐式重试。本轮不读取凭证或发送模型请求。

- 容量 1 下各方法使用相同订单、到货、公开信息权限、候选器、TopK、候选展示规则、旋转权限、公共物理检查和选后监测。轨迹分化后不要求每步候选池逐字相同。

- 新增特征、训练或候选编码变化须说明；保留论文核心机制与具体差异证据。只成功 import 或前向推理不等于复现原论文。
- 原生权重零样本迁移、项目数据重训、随机初始化测试分别标记。不得只使用失配权重的差成绩就声称普遍优于 PCT。
- 当前已暴露数据只能支撑开发诊断；正式泛化需要另行冻结合格留出来源。训练、调参、模型选择不能使用测试结果。
- 评价包含完成状态、件数/体积/质量装入比例、固定容器利用率、垛高、包络利用率、预测失稳进度、不可评价/技术错误、时延及可得成本。未实现或未运行写 `NOT_IMPLEMENTED` / `NOT_RUN`，未知写 `UNKNOWN`，不填虚假 0。
- 全部箱体装完时固定容器利用率相同，需看紧凑性；少装造成的低垛高不能单独称改善。公共硬过滤的零违规不能当作选择器创新。
- 空池不证明全局无解；有限分叉不证明全局最优；重复运行不增加独立来源数。保留负例、技术失败、取消与未运行的完整分母。
- 若只接通 PCT-adapted 而未完成原生表现检查，必须将复现充分性列为限制，不能把适配工程验收写成强基线收益已验证。
