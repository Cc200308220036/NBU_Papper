## 环境与实际验证

已定位的现有解释器为CPython3.12.14，arm64，ABI cpython-312，二进制摘要及实际路径归档在environment.json；具有NumPy2.3.5，但无jsonschema及其依赖。系统python3为3.9.6，不能解析当前公共contracts.py的PEP701表达式。此次未安装依赖。P1-A不需要Torch、Gym、SciPy、pytest或GPU；使用unittest及固定源码路径，不安装主工程全部extras。

实际命令均从仓库根执行，`PCT_PY`表示环境记录中已定位解释器，不能以系统python3替代：

```bash
PYTHONPATH=PCT/src python3 -m pct_baseline.cli prepare-data --spec PCT/configs/data_b1_v1.json --output PCT/outputs/PCT_P1_A_20261114_01/data
PYTHONDONTWRITEBYTECODE=1 "$PCT_PY" PCT/scripts/verify_p1a.py --output PCT/outputs/PCT_P1_A_20261114_01/verification_final
```

prepare-data首次实际采用系统3.9标准库成功，公共集成及最终测试采用3.12。验证脚本拒绝覆写既有目录；重验必须指定新输出目录。脚本逐条保存unittest、validate-data、full-schema、公共导入、AST、旧资源字节及只读Git检查。full-schema和公共contracts导入均实际exit 1，原因为ModuleNotFoundError: jsonschema。数据CLI验证后无planner、selector、generator、LP或网络客户端导入；数据派生及测试仅写新交付或临时目录，不覆写父包。旧首次verification记录11项通过，新增漂移测试后verification_final为13项通过、5项跳过，完整18项分母保留。
