# O4三类约束、选择器与独立评价语义

版本：o4_policy_v1。规则最多32条，单选择器深度≤4（根为1），每个object_ids最多64个已到货ID。

## 约束

- no_top_load：目标累计顶部载荷≤1e-6 kg，等价业务限值0。对象自身质量不算其顶部载荷。
- max_top_load：累计顶部载荷≤常数或该对象labels.max_top_load_kg＋1e-6 kg。多个未覆盖限载合取，取较严值。
- forbidden_contact：左右对象集合之间禁止水平或垂直直接面接触，关系对称、排除自身；边/点接触不计。面相邻容差1e-6 mm，另外两个轴须有大于容差的正长度重叠。

程序从位姿恢复支撑，以接触面积分摊质量并逐层传递。执行器按高度自上而下累计；参考解释器分别把每个对象自身质量递归传给底层，避免调用同一个最终判定。二者均不相信记录中的旧load/support缓存。

## 选择与例外

支持all、object_ids、eq、lt/le/gt/ge、and/or/not。数值比较只用于声明的非负有限kg字段；boolean不得当数值。类别、布尔值及重量等级严格检查类型与取值。选择器保持符号形式，在每个真实或评测状态展开，不提前固化未来对象。

规则有rule_id、priority和overrides。数值较小优先，覆盖引用须指向同一限载族且较低优先规则；禁止未知、自引用、环和接触覆盖。接触例外通过集合排除表达。

对于某对象，先求全部适用限载规则；任何适用规则显式指向的旧规则在该对象上失效，其余生效。覆盖仅在对象匹配时生效；覆盖链按适用声明传递解释。priority只约束覆盖边，不会单独使无覆盖的另一规则失效。业务硬规则不被几何软目标抵消。

规范完整作业单中：r1全体按标签；r2禁压对象限值0且覆盖r1；r3仅“玻璃制品＋已加固＋无禁压”对象限值2 kg且覆盖r1；r4食品/清洁用品禁止接触。加固但禁压仍适用r2，小家电不适用r3，物理承载永不被覆盖。

## 评价与判错

固定状态先分别计算方法和参考的before/after、适用对象、活动规则、逐箱载荷、限值、接触对、违规及允许候选。未知pick ID拒绝。无参考可行候选保留，不计作语义成功或完整订单失败。

规则语义比较对规则ID重命名、规则重排、and/or子式顺序和接触左右交换规范化，保留选择条件、阈值与覆盖关系；JSON结构一致、规范结构一致、有限探测一致分别报告。有限探测覆盖提供的对象以及40种类别/布尔组合和8个载荷值，不构成无限表达式等价证明。

执行器与参考解释器不共享最终匹配、覆盖、载荷或违规函数。36个金标准提供独立明确期望，分为六组各6例；包含零/近容差载荷、间接加载、多支撑面积分摊、点/边/面接触、双方到货顺序、条件边界及六种包装画像。人工审阅状态为PENDING_HUMAN_REVIEW，程序通过不冒充人工签认。

遗漏规则、错对象与错阈值只要结构合法就原样进入方法评价；不能用隐藏答案补齐。参考评价仅生成审计结果，不能参与方法选址。当前模块不提交在线动作。
