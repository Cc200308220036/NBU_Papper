# O4公共图像与标签箱面协议

日期：2026-10-22。版本：`o4_public_render_v1`、`o4_visual_facts_v1`、`o4_visual_input_v1`。对应A5；准确观测、无感知估计。不改变原A/B/C/F协议和三约束含义。

## 输入和隔离边界

渲染入口只接受无图像附件的`o4_request_v1`，或完整`o4_buffer_state_v1`。裸缓冲observation没有槽位、容量和EOS，明确拒绝，不能猜测。未知字段、未来对象、候选、参考政策和允许集合均不能进入输入。

单位沿用mm/kg、托盘底面中心坐标系。公共事实包括准确ID、尺寸、质量、已码位姿、货物类别、加固、禁压、标签限载、物理承载、stackable、fragile及weight_class。业务说明仍保留在编译请求中，但不影响图像绘制。图像不呈现有效规则、允许动作、违规诊断、Oracle颜色或答案水印。

## 箱面和印刷位置

旧观测没有标签所属箱面。A5引入独立公共视觉事实侧表，先声明可复现的仿真印刷版式，再生成图像；不把版式说成从实物图片测量所得。

首版印刷版式`o4_simulated_label_pos_x_v1`：每箱标签均位于物体本地`pos_x`面。面内u从该面y负侧到正侧、v从底到顶，矩形范围为`[0.15,0.25,0.85,0.75]`。印刷载荷信息是原始标签值，即使禁压为true仍保留标签限载，不按业务规则改成0。

本地原点位于箱底中心；六面为pos/neg_x、pos/neg_y、pos/neg_z，各有本地法向和四个本地顶点。已码箱按公共yaw绕+Z逆时针旋转后平移：0度保持，90度将本地+X转到全局+Y。已码箱提供全局顶点和法向；待码箱全局顶点、法向为null，不能赋予托盘位姿。

首版面位置固定且公开，不研究隐藏标签识别、任意箱面的版式生成、180/270度候选或“标签朝外”的业务约束。E3/E4仍是后续阶段；此处的面变换事实不构成其约束功能已实现。

## 图像构成

1. 托盘XY/XZ/YZ线框投影：只画已码箱的真实几何，提供单位、容器尺寸、对象索引；明确线框可以显示遮挡对象，不冒充真实相机可见性。
2. 独立待码区示意：F使用真实公共槽位和容量；单箱没有槽位事实时显示当前箱且标注位姿未定义。槽位示意不是暂存区物理几何或托盘坐标。
3. 逐箱局部卡片：本地箱面示意标出+X面及面内标签位置，右侧为标签面展开；额外物理参数单独注明为公共参数，不由标签推断。完整ID与数值不静默截断。
4. 标签页：每页最多六张原尺寸卡片，便于附件传递；原始逐箱PNG仍保留。每份图像输入使用场景图及全部标签页，覆盖所有已码和已到货对象。

卡片没有全局位姿，随箱体移动可以复用；场景图和视觉事实准确绑定当前已码/待码状态。相同事实不因方法、请求ID或业务文本不同而添加色彩提示。

## 结构与绑定

`visual_facts`封闭字段包括版本、单位、container、mode、buffer_capacity、end_of_stream、objects及facts_digest。每个objects条目包含准确原对象事实、位置角色、槽位/到货序号、六面及标签payload。schema在`o4/visual/schemas/facts.json`，随Python包分发。

`o4_visual_input_v1`封闭字段为public_request、visual_facts、visual_facts_digest、images、condition和binding_digest。文本/图像条件获得完全相同的视觉事实；图像条件仅额外携带PNG。

附件元数据仍使用原协议的path/sha256；增加附件后重算observation_digest，缓冲模式再重算buffer_state_hash。整体binding_digest覆盖所有输入及视觉事实。图片路径必须是交付根目录内的相对PNG，不允许绝对路径、`..`或指向外部的符号链接。

图像文件名按公开事实/版式版本内容摘要寻址，独立记录文件SHA256和解码RGB像素SHA256。PNG只允许rendering_version和facts_digest两个文本元数据，不写入时钟、来源划分、规则或参考答案。

## 确定性和独立校验

固定字体文件、字体SHA256、Pillow/Python/zlib版本及渲染配置；保存字体快照。确定性门槛为相同公开事实、版本和环境下图元与PNG字节重复一致，不宣称任意字体或跨渲染库环境天然字节一致。

生产模块生成图元和PNG；独立校验器不调用生产渲染器的图元生成函数，分别重算显示文本、本地六面、90度法向、投影及标签范围，再独立栅格化并逐像素比较。只共享底层Pillow和公共输入schema，不用“manifest自称正确”代替图像事实一致。

破坏标签文本、箱面法向或PNG像素，即使重新计算相应摘要，也必须被语义/像素校验发现。假客户端仅验证实际PNG字节传输和绑定；真实模型准确率、OCR能力及图像增量留待D，不从A5推导。
