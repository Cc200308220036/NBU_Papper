# O4受控中文编译语法与错误码

版本：o4_controlled_chinese_v1。规则编译器不读取数据集、参考文件或样本答案表；它是明确发布语法的确定性基线，不声称任意自然语言理解。

## 通用组合语法

每条规则写作：`规则r1：约束正文；优先级20；覆盖无。` 多条直接连接或加换行。覆盖多条用逗号，如`覆盖r1,r2`。

约束正文支持：

- `对（选择器），禁止顶部加载`
- `对（选择器），累计顶部限载按标签`
- `对（选择器），累计顶部限载为2kg`
- `禁止（左选择器）与（右选择器）直接面接触`

选择器支持：

- 全部箱体；对象（item_01,item_02）。
- 字段＋比较＋值，例如货物类别等于玻璃制品、质量不小于2kg、禁压标记等于是。
- 同时满足（子式，子式）；任一满足（子式，子式）；不满足（子式）。可组合嵌套，最大深度4。

字段词：货物类别、包装加固、禁压标记、标签限载、物理限载、质量、易碎、重量等级。类别词：食品、玻璃制品、电子产品、清洁用品、其他。布尔词：是/否。重量等级：轻/中/重。比较词：等于、小于、不大于、大于、不小于；有序比较仅数值字段。数值必须带kg，禁止猜测单位。

同义控制通过规则重排、and/or子式重排、对称接触左右交换及空白换行产生；这些属于开发语法，不是未见自然语言测试。

## 规范作业单

另外逐子句解析实现规范第3.3节以下明确自然表达；限载数值可替换，不通过整段文本查答案：

> 本订单普通箱按各自标签的累计顶部限载执行；带禁压标记的箱体禁止顶部加载。已加固且无禁压标记的玻璃制品外箱，改按订单指定的2 kg业务限载执行，替代其标签业务限载。食品外箱与清洁用品外箱允许同托盘，但不得直接面接触。所有箱体仍须满足独立物理承载限制。

任意超出已发布语法的表达明确拒绝；不返回空AST掩盖不支持。只有显式输入“无额外业务硬约束。”才能编译为空规则。

## 错误码与离线模型边界

| 错误码 | 含义 |
|---|---|
| invalid_observation | 公共结构、字段、单位、数值、ID唯一性或准确属性对应错误 |
| invalid_binding | 请求自身摘要或响应绑定不一致 |
| invalid_ast | AST结构、类型、对象、表达式/条数、覆盖关系错误 |
| unsupported_construct | 语言或本阶段能力不支持；真实API接口未开放 |
| invalid_candidate | 候选引用不是当前可用箱 |
| provider_error | 离线替身注入的服务/传输错误，不代表真实服务调用 |

离线client接受声明的模拟响应，保留原始响应/首次结果/修复记录。格式或绑定失败最多修复一次；服务失败不自动重试。修复提示仅含公共请求及错误码，不含私有真值。合法但漏规则的响应不触发答案修复。正式模型、价格和真实可靠性留待O4-D。
