## 1. 建议结论与研究问题

建议保留JM0—JM6主线，在当前JM2-B1停点前增加一轮有边界的“条件定义与证据设计修订”，然后按原阶段恢复推进。优先建立少量能对应当前候选取舍的经验族，先检验内容和匹配，再进行局部选择与整单评价。不要直接进入B2/C，不再重复五卡审核，也不先扩大整单矩阵。

要检验的核心问题是：**在当前公开状态下，当候选动作在某种可观察资源关系上存在取舍时，来自同类历史比较的有条件经验，能否帮助Jev作出比无经验、一般提醒及无关上下文更好的选择？**

“有效作用”分为五个可分别失败的环节：

1. 当前候选中确实存在经验所描述的取舍；
2. 当前可观察信息足以判断经验适用或不适用；
3. 请求中的短片段能把条件、A/B角色、方向和代价讲清；
4. Jev的实际选择出现与内容相关的变化，或已有正确选择被保留；
5. 在相同无经验后续及后续整单评价中，结果达到事前约定的收益和风险条件。

前四项不保证第五项，动作变化也不保证改善。方案的目标是逐层发现失败原因，而不是保证E路线胜出。

## 3. 目前为什么没有形成可用经验

### 3.1 事实、可检索条件和执行建议之间缺少中间连接

当前材料保存了几何与A/B动作，并不是“没有结构数据”。但“保存了完整几何”“能计算某个特征”“这个特征足以限定某条经验”是三件事。

代码已有箱数、最大垛高、投影并集、包络跨度、平均中心、面接触数量、总承载账目和动作属性。连续空隙、可用顶面、承载路径等明确未实现。P05所需的局部空隙/邻接关系，不能被一个总体包络或平均尺寸可靠替代。

### 3.2 当前动作对应过窄，直接用于检索也可能全空

`bind_contrast()`目前要求全部`STRUCTURAL_KEYS`精确相等、容器相等，且全部角色属性方向一致。这适合A1保守诊断，不适合直接充当成熟的跨状态检索器：

- 全局平均中心、总箱数等无关变化可能导致拒绝；
- 即使全部已注册标量相等，局部支撑或空隙仍可能不同；
- 同样的x/y增减方向不等于同样的“沿边界收拢”关系；
- 多个对应只能说明存在候选关系，不能自动决定哪个当前动作更好。

改进需要改为“逐经验族的必要条件＋局部动作关系”，而不是把精确相等统一换成一个更宽阈值。

### 3.3 采样覆盖没有围绕可比较的经验族组织

现有采点遵循最高概率并列/近并列及阶段程序，避免了按胜负选点，但并不保证每个族会在两个来源、两个不同起点出现。同箱位移3点也不等于同一个位置策略有3点支持。

若后续仍按同样程序只积累零散点，可能不断增加档案，却无法形成共同条件下的跨起点比较。新采样需同时登记“原概率层”和“公开结构取舍层”，不能看结果后才把赢的点归为一族。

### 3.4 不应要求每条生成前事实都已经是一条成熟策略

原方案允许提炼提出新条件、假设及`INSUFFICIENT_EVIDENCE`。实际限定B1为安全收口，只有拒绝路径，没有真实放行能力。这并非已知代码错误，但后续需要明确：

- **档案充分**：历史事实和代价是否真实、完整；
- **可研究输入充分**：是否存在具体、可观察、可反驳的候选取舍问题；
- **候选内容合格**：生成后的声明是否有注册条件、范围及内容审核；
- **可执行**：是否经过跨起点、检索及局部效果验证。

建议在新合同中明确允许“可研究输入”产生受限候选假设；它不是新增执行身份，不自动把旧五卡升级为`CANDIDATE_MEMORY`。若仍缺必要当前条件，则先补定义，不能靠自由文本绕过。

## 4. 先收窄两个经验族，而非同时开发全部空间特征

### 4.1 优先族F-S：同箱位置对当前空间分割的取舍

研究对象：同箱、同朝向、同底高的两个精确位置，比较它们对当前某个公开平面自由区域的分割，以及对当前缓冲箱底面几何容纳的影响。P05是探索线索，P01/P03是必须保留的反向或中性约束，不能因三者同属平移就合并。

拟议假设：在注册的局部边界/邻接条件下，某类位置保留了对当前缓冲箱更相关的连续矩形区域，其同策略后续装入量可能更高。该假设必须接受“区域更大但收益没有增加”及方向相反的结果。

第一版只研究地板或一个明确注册的水平层；不一次解决任意三维自由空间。若P05原件不足以支持所选平面定义，保留为档案，不补造几何。

### 4.2 次优先族F-R：跨箱选择的局部资源保留取舍

研究对象：候选箱体在尺寸、质量、可堆叠性或包装承载与位置之间有联合变化；比较其占据的局部区域、剩余高度和公开面积承载账目。P02提供负向线索，P04提供单次联合变化边界。

第一轮只能选一个可测的联合关系，例如“相同已注册支撑关系下，更低但底面更大的候选与更高但底面更小的候选”。不得概括成“容量大优先”“轻箱优先”或“低箱优先”。若没有两个不同来源组件的同类取舍，先只做F-S，不用无关跨箱点补足F-R。

### 4.3 旧五卡的使用安排

| 卡 | 建议用途 | 不做的升级 |
|---|---|---|
| P05 | F-S条件定义的首个探索案例，核对局部区域能否表达 | 体积/质量局部改善不变为“必然释放空间” |
| P02 | F-R联合取舍的负例及范围检查 | 不把容量/高度单属性当原因 |
| P01 | 检查装入量方向与高度/成本方向分离的表达能力 | 不覆盖`CONFLICTING_LOCAL_OBSERVATIONS`，不要求全部指标同向才准许提出窄假设 |
| P03 | 中性档案、过度推广和角色错配反例 | 不写成普遍等价规则；它可成为某个过强方向声明的审查材料 |
| P04 | 联合属性、支撑/朝向变化和单次等级的拒绝检查 | 不伪造重复支持，不拆成旋转单因子机制 |

这些用途是新方案分析建议；旧审核、卡片、摘要与门保持原样。新条件若由已见结果启发，明确标记探索性，必须在新结果产生前冻结。

## 5. 特征与条件：从全局均值转向局部、候选相关描述

### 5.1 首轮实现优先级

| 优先级 | 拟议描述 | 计算定义与限制 | 用途 |
|---|---|---|---|
| P0 | 候选到容器四壁的净距 | 用底面边界与容器边界作差，单位mm；保留四个方向，不能仅保留最小值 | 描述靠边/居中关系，替代绝对x/y方向捷径 |
| P0 | 候选与局部邻接面的距离、投影交叠 | 从公开放置几何得到带方向的相对关系；无邻居标NA | 定义“向某个可观察边界收拢”，不以历史箱ID作为迁移条件 |
| P0 | 直接支撑关系摘要 | 地板/单箱/多箱，支撑层、相交面积及来源角色；复用公开几何与面积账目，缺失则UNKNOWN | 区分同位置数字、不同支撑结构；不含PCT反力或预评标签 |
| P0 | 当前缓冲的关系分布 | 除均值外保留相关箱的长宽高、质量、stackable及当前候选覆盖；按本地身份区分同属性不同箱 | 防止均值相同却无法解释具体取舍 |
| P1，仅F-S | 指定平面的自由矩形分割 | 减去该平面实际阻挡区域，以矩形并/差和明确高度条件定义；保留区域边界和最大空矩形等可核对量 | 研究连续空间；面积大不等于可装件数多 |
| P1，仅F-S | 当前缓冲底面容纳代理 | 逐缓冲箱0/90底面与上述矩形作尺寸比较，记录可容纳身份集合；已选箱从剩余缓冲统计排除 | 只表示二维几何容纳可能，不是物理可执行或未来装入预测 |
| P1，仅F-R | 指定顶面的暴露区域和局部面积承载账目 | 可堆叠顶面减去上方遮挡，记录其局部几何及现有公开余量；先限定精确层定义 | 不能把总顶面积、总剩余承载直接当未来可用资源 |
| 后置 | 整体三维自由空间、复杂承载路径、学习型价值预测、embedding/在线LLM重排 | 本轮不纳入首版，确有必要再单独立项 | 控制工程量和归因混淆 |

所有新特征都是拟议能力，不能把现有`NOT_IMPLEMENTED`改写为已实现。只有声明确实依赖的特征才纳入该族必要集合；不得要求每张卡具备所有空间特征。

### 5.2 候选相关特征的计算边界

允许基于已有精确动作，纯函数计算其占据矩形、墙距和静态几何差分。例如：

`wall_clearance_left(a) = x_min(a) - x_min(container)`。

对指定平面自由区`F_z(S)`，可定义`F_z(S,a)`为加入动作几何占据后的区域差分，并提取最大的轴对齐空矩形面积及缓冲底面容纳集合。必须明确这个平面上哪些箱体构成阻挡、动作是否跨越该平面、净高条件与0/90尺寸；否则结果记UNKNOWN。不能仅凭XY投影就声称存在三维可放空间。

这类计算不调用`assess_candidate`、不产生候选稳定标签、不提交状态、不重新生成或裁剪候选池、不搜索后续动作、不复制物理引擎。若某项需要原物理检查或稳定性求解才能成立，就从该代理声明中排除，而不是偷偷预评所有候选。

新几何事实若进入基础候选描述，应对N/T/E/U/G全部方法一致提供；否则“经验作用”会与额外几何信息混淆。历史与当前使用同一版本函数、同一坐标和缺失合同。

**纯说明性算例，不是实际卡、测试fixture或新实验数据：**设一个已确认净高足够的地板矩形为1000×600 mm，待选同一箱的底面为200×600 mm。为便于说明，把局部区域平移表示为`[0,1000]×[0,600]`，正式协议仍用原坐标。

- 位置A占据`[400,600]×[0,600]`，左右各留下400×600 mm；
- 位置B占据`[0,200]×[0,600]`，留下800×600 mm；
- 当前剩余缓冲若有500×500 mm底面的箱，其底面在B的剩余区域中可以容纳，在A的两侧均不能容纳；这给出了具体的当前候选取舍；
- 若剩余箱底面改为350×500 mm，两侧关系发生变化，两位置均有二维容纳区域，不能沿用“只有B保留容纳机会”的条件；
- 净高、stackable、承载或支撑未满足时，二维容纳也不能算可执行，更不能保证最终装入量改善。

这里模型需要理解的是“与当前缓冲相关的空间分割”，不是“靠左更好”。正式验证还须包含镜像、平移及相似面积但不同连通关系的构造检查，排除绝对坐标捷径；这些检查只验证表达和算法，不增加真实经验起点数。

### 5.3 必要条件与软相似度分开

每族先列出少量必要条件，如干预类型、地板/支撑层类型、两侧角色都存在、关键局部区域可计算。缺失时拒绝；不能被其他相似项抵消。

墙距区间、尺寸比或空隙宽度区间的选择应由几何意义、训练公开分布和测量分辨率确定，在新后缀结果前冻结。不能围绕P05的获胜数值拟合一个恰好通过的阈值。非必要全局特征只用于排序或报告，不要求所有箱数、平均中心和包络完全相等。

## 6. 经验内容：一张卡只表达一种有边界的取舍

### 6.1 三级保存，避免把审计材料全部塞进请求

1. **私有证据层**：完整起点/池、A/B精确动作、全部分支、结果向量、重复、来源、成本及审核引用。
2. **候选内容层**：注册条件、动作角色、支持/中性/反例、方向与代价、UNKNOWN、可反驳预测和证据范围。
3. **请求片段层**：短的使用场景、两侧取舍、获批建议或局部观察、必要代价和不适用条件；引用用简短证据标识，完整SHA/JSON指针留私有侧。

不能通过删去反例、关键条件或代价缩短文本。首轮建议最多一条记忆，长度上限在JM2-C冻结；不要现在同时搜索不同条数和多种措辞。

### 6.2 拟议卡片字段与审核职责

| 字段 | 内容 |
|---|---|
| `family_id` / `content_version` | 经验族及新身份，旧卡引用保留 |
| `observable_scope` | 已注册条件、单位、必要字段、排除条件；不含未来箱和私有整单答案 |
| `decision_contrast` | A/B匿名角色、同箱/跨箱、位置/朝向类别及必要不变量 |
| `observed_facts` | 全部有效比较与代价的准确摘要，事实ID回指 |
| `advice` | 有条件的比较方向；允许负向教训，禁止绝对Cxx、固定次序和序号捷径 |
| `mechanism_hypothesis` | 可选，明确HYPOTHESIS；未知可以为空，不强迫解释出机制 |
| `falsifiable_prediction` | 在什么公开条件和后续策略下，什么结果会支持/反驳/收窄它 |
| `support_conflict_scope` | 不同起点/来源、同点重复、中性、相反和技术无效分别计数 |
| `continuation_identity` | 冻结无经验Jev身份；换后续模型后的迁移未经验证 |
| `review_refs` / `lifecycle` | 专门审核窗口的实际结论、证据、参与披露和候选/执行权限 |

示例仅用于表达设计，**不是已批准的P05经验**：

> 在已注册的地板局部边界条件成立、同箱同朝向的候选位置之间，比较其保留的连续矩形区域及对当前剩余缓冲底面的容纳关系。若拟议B型关系成立，候选假设为B可能保留更好的后续装入机会；历史局部体积增加不代表多装件数、降低垛高或缩短时延。条件缺失或相关底面容纳关系不存在时，不应用该方向。

这段仍需以真实新证据和可计算条件替换“拟议关系”，不能原样当成合格卡；否则仍接近通用提醒。合格版本必须明确A/B究竟在何种已注册关系上不同，并给出可反驳的结果方向。

### 6.3 方向审核不要强求所有指标一致

沿用稳定完成优先、装入体积为主要目标的比较合同，完整报告件数、质量、高度、包络、时延和费用。P01的高度冲突限制“降低垛高”声明，但并不抹去体积两次改善的事实；P05的件数不变限制“多装件”声明，但不抹去体积/质量变化。

保留历史整体证据等级，在新声明私有侧增加“针对哪个终点支持/冲突”的审核记录，不重标旧卡。是否允许一个保留高度代价的候选建议，按预先冻结的风险合同判断，不能要求所有指标普遍占优，也不能隐去低优先级代价。

## 7. 审核改为专门窗口，不再设置两名人工要求

用户最新要求优先于JM0-B历史设计。后续新任务合同采用：**生成/开发窗口提交冻结对象，专门负责审核的窗口执行事实、范围、内容及准入审核。** 不要求两名人工，不默认调用付费审核模型，也不在本轮启动审核子代理。

审核窗口至少记录：会话/角色及执行模型的可得身份、任务授权来源、是否参与受审开发/生成、输入清单与摘要、逐声明结论及理由、实际执行的验证、未运行事项。无法取得的平台消息ID或模型精确版本记`NOT_AVAILABLE`或`UNKNOWN`；窗口使用模型审核应如实记录，不伪装成人工，也不另行要求调用审核API。若同一窗口曾参与受审对象，披露限制；专门审核角色与组织独立性分别描述。

可执行流程：

1. 开发/生成端冻结卡片及事实包，提交完整正负分母；
2. 审核端先核对事实、角色及引用，再判断必要条件、声明范围、具体候选区分和可反驳性；
3. 输出`APPROVED_SCOPED`、`ARCHIVE_ONLY`、`REJECTED`或`PENDING`及理由；状态名称为拟议，需新Schema集中登记；
4. 只有新合同规定的内容门通过，才能取得候选诊断权限；局部/整单执行资格仍需JM3、JM4-M证据；
5. 允许零批准，禁止审核端为推进流程生成假条件或静默修改卡片；有分歧保留PENDING，新版本另审，不重复求批准。

程序校验不替代内容审核，窗口审核不替代效果实验。旧五卡审核已经完成，无需再向同类窗口重复提交同样对象。新审核只针对新声明、新条件或新证据，且不得倒写旧批准。

JM0-B旧`chosen_mechanism`、后续标注合同中的“两名人工”表述，应在新修订收据中列明被本轮用户要求替代的条款；不改写历史JSON。专门窗口做适用性标注时，还须隐藏检索器接受结果和当前订单终态；有条件可进行同窗口间隔复核，但不把这种复核称两名独立标注。

## 8. 新训练证据：按族配对，按结构采点，按来源分组

### 8.1 先做材料可行性清单，再决定是否新增调用

零调用阶段应盘点：现有保存公开状态是否足以定义特征、各族在哪些不同起点存在两侧候选、来源组件、哪些材料已暴露，以及调参/锁定核验/局部开发/整单dev/eval能否隔离。

现有3个保守组件不足以默认覆盖全部后续分区。不得将同订单变体、镜像/旋转复制或新种子直接计作新独立来源；真实来源不足时，应选择补充可审计新材料，或另行收窄为共享素材内的描述性研究。单纯增加同来源重复不能解除来源限制。

### 8.2 最小新增训练设计（仅拟议，需独立冻结和授权）

建议首轮最多2族，每族2个不同训练起点，且来自2个不同保守来源组件；总4个起点。每点保留“原Jev动作A＋一个结构选择程序确定的替代B”，每动作2个独立后缀槽位：

`2族 × 2起点 × 2动作 × 2槽位 = 16条新后缀`。

如需要新无经验基线来取得起点，最多4个完整基线job；实际任务ID、原始来源、阶段、箱数及逐job最大发送须先冻结。旧五点用于探索，不将已观察结果的点冒充新验证点。若一个族没有合格起点，如实缩小范围/停止，不自动换更多订单；若基线未找到点，保留该基线与缺口，不花剩余额度找赢家。

这16后缀是**新增研究方案**，不是把历史48上限减去18后继续使用余额。原授权已经结束，新范围、执行源码和许可必须独立建立；不能为重用旧运行而重签旧身份。

### 8.3 采点与替代动作选择

- 新点只按当前公开几何、缓冲、完整候选池和原生概率选择，不看后缀结果、未来箱、监测预评或旧胜负。
- 先冻结经验族的必要结构关系、阶段、同箱/跨箱及A/B不变量；随后按确定性的序号/动作摘要选点。
- 原精确并列/近并列采样层保留其名称和解释。若其不能覆盖拟议族，可以另行登记`STRUCTURAL_CONTRAST`层；该层允许的概率范围、替代动作程序与结论范围必须在发送前冻结，不能静默放宽原阈值。
- 参考分支必须是同一保存前状态下的原动作；强制A/B首步之后全部使用同一无经验Jev后续。首步监测失败立即停该分支，不能再选其他B。
- 负向、无收益、不同指标权衡和重复冲突全部保留。每族2起点/2重复只是有限筛查，不是充分统计支持。

### 8.4 隐藏到货与后续随机性的边界

后续到货和选择可导致相同当前状态下的终态变化。在线条件不得加入未来箱来解释结果。经验的研究目标应是“冻结到货分布和后续策略范围内的有边界观察/期望优势”，不是“遇到该条件必然更好”。

同一保存任务的A/B沿相同到货事实运行；独立重复记录实际服务随机性。若平台没有可冻结随机种子，不声称后缀随机量已经完全配对。不同到货任务可作为新的注册训练起点，但必须按来源/生成家族计数，不能把一次任务切成很多独立样本。

## 9. 检索改进：先问是否适用，再问哪条最相关

### 9.1 R0保留，R1使用逐族门控

R0维持主方案约定的兼容九维比较、旧距离公式和冻结阈值，但历史/当前特征统一口径。它与R1使用同一候选库、正文预算及后续执行白名单，不把旧库对新库的变化伪称检索收益。

R1首版建议采用确定性流程：

`来源/权限 → 阶段与干预类型 → 本族必要条件 → A/B角色及局部关系 → 适用候选内排序 → 正文预算 → MemoryView`。

首轮库很小，直接遍历全部卡片即可，无需先接embedding或在线LLM重排。排序只用该族相关的归一化特征，权重及尺度在调参集确定、锁定前冻结；不按训练收益大小、最高置信度自评或历史名次排序。

关键缺失、只有一侧候选、相反证据未解决、超范围和来源不合格都应拒绝。合理空命中是必要行为，但全空不能算检索成功。诊断模式可检查候选记忆，正常整单只接受执行白名单。

### 9.2 角色匹配从绝对方向转成关系方向

同箱优先匹配“同一当前箱、相同朝向/底高、向已注册边界收拢与保留某区域之间的差异”，而不是历史`x增加/y减少`。跨箱匹配联合属性方向和局部支撑关系，不能只比较平均尺寸。

内部保存当前候选对应集合与判据；不重排、删减或增加公共候选，也不把历史Cxx映射成当前答案。多个对应只有在该族定义下同义时才可保留全部；若不同对应会产生相反建议，记`CONTRAST_BINDING_AMBIGUOUS`拒绝，不挑一个有利对应。

若将当前候选几何描述或对应关系加入请求，应明确这是新增输入合同，并使相关描述在所有对照中一致。T/E的共同事实与匿名角色表达一致，不能让E额外拿到一个直接推荐当前标签的工具。

### 9.3 离线核验集怎么构造

真实保存状态按来源组件和近重复分组，分调参与锁定核验；再与JM4局部开发、整单dev和正式eval隔离。来源不够时登记缺口，不用相邻状态凑独立分母。

专门审核窗口只看公开状态、原池、卡片及必要条件定义，标`APPLICABLE / FORBIDDEN_OR_NOT_APPLICABLE / UNKNOWN`，同时核对动作角色；不看该订单终态胜负或R0/R1是否接受。

必须覆盖：真实适用、阶段不符、同箱/跨箱错配、支撑/邻接不同、关键量缺失、仅一侧角色、歧义及反向证据。几何变换构造可验证函数和拒绝行为，但不能冒充真实迁移支持。

报告已知标签precision/recall、UNKNOWN接受、错误注入、错误拒绝、全空比例、各族覆盖、正文长度和来源分母。某族没有真实适用正例时，precision/recall记NA或相应缺口，不能以全拒绝获得高分。沿用冻结合同的零已知禁止迁移接受等有限筛查要求，不把观测零错误解释成真实错误率为零。

## 10. 如何证明内容作用于Jev选择，而非只是进入请求

### 10.1 JM4-A先做接口验收

沿用最多1次T＋1次E真实非空多候选请求。固定状态定位，空命中不换状态。保存实际body、响应、Cxx到精确动作、选后监测及提交/终止；库非空、检索非空、view非空、body非空、确认发送分开计数。

### 10.2 JM4-M保留五条件同状态对照

| 条件 | 保留的作用 | 对应问题 |
|---|---|---|
| L-N | 空记忆，公共候选描述一致 | 无经验选择基线 |
| L-T | 同源事实案例 | 案例事实是否足够 |
| L-E | 完整条件化经验 | 提炼后的具体取舍是否有增量 |
| L-A | 删除E关键方向与对应预测，保留约定事实/条件/代价 | 方向建议的删减诊断 |
| L-G | 冻结一般提醒 | 是否超出“多考虑空间/承载”等一般提醒 |

保持原方案最多4个开发状态、每状态5次独立选择，总20请求。状态不能参与检索调参或锁定核验；选择顺序按冻结平衡规则交错，记录服务时间块。每条件只发一次，不为得到不同动作反复抽样。

分别记录：实际精确动作、是否变化、是否匹配经验角色、概率向量变化（仅接口真实返回时）、不适用时是否被拒绝，以及全部后缀结果。概率不是物理置信度；不要求Jev输出思维链，不以模型自述“参考了经验”当收益证据。

### 10.3 原“3动作/24后缀”上限存在可预见的识别限制

原方案每状态最多保留3个去重动作、每动作2后缀，4状态总24后缀。但E与N/A/G/T可能产生4—5个不同动作，届时部分关键对照没有后缀，不能比较完整内容增量。

建议默认保留原上限，预先将N、E及一个注册关键对照作为动作保留优先级；缺少现行准入合同要求的其他比较时，该卡DEFER，不用已有三动作代替全部对照。

如果研究目标明确要求在同一轮比较E与N/A/G，另一可选设计是事前将上限修订为每状态4个动作：`4状态×4动作×2重复=32后缀`，保留N/E/A/G；T若是第五动作则无相应效果证据。完整五条件动作效果最多需40后缀。**32/40均超出原24上限，必须新冻结合同与明确授权，不是本文追加额度。** 不在看到动作或收益后决定扩容；首轮优先接受原上限带来的DEFER。

相同动作保留所有条件记录，但不虚增独立动作证据；没有动作差异可能是N已经选对，也可能内容未发挥作用，不能直接宣称无用或有效。

### 10.4 成效判断与失败归因

| 观察 | 可支持的判断 | 下一步 |
|---|---|---|
| 没有合格适用状态/角色 | 内容范围或数据覆盖不满足 | 停在材料门，不发模型找命中 |
| 存在适用状态但检索拒绝 | R1条件/匹配可能过窄 | 只用调参区修订，新锁定核验；不改测试结果 |
| body有正确内容，选择基本相同 | 内容选择增量未识别 | 结合N是否已采取同方向报告，不为制造变化改提示 |
| E改变动作，后缀退化/冲突 | 建议有干扰或边界不足 | REVISE/DEFER；新条件不得在原测试上重新获证 |
| E优于N，但与G/A无可识别差异 | 有局部作用线索，专门内容增量未建立 | 不宣称经验提炼优于一般提醒 |
| 跨不同起点、来源满足注册效果/风险且关键对照齐全 | 可以按合同审核该族执行资格 | 仍需整单受控先导和未见评价 |

执行门继承JM0-B冻结的跨起点/来源、关键反向证据与效果条件；缺关键对照、覆盖或效应精度即DEFER。本文不以降低门槛保证通过；任何实质改变须在新任务合同中写出理由和主张范围。

下面`JM-REV0`—`JM-REV3`是**本改进方案的工作包标识**，与既有检索R0/R1分别命名，不是已实现接口，也不改变原JM阶段编号。

|---|---|---|---|

### 13.2 数据流及失败语义

```text
保存公开前状态/完整池
```

运行时仍为“公共候选→独立选择→保存选择→独立副本监测→保存结果→提交或终止”。监测只作用于已选精确动作。候选级几何描述不含PCT稳定预评。`UNSTABLE`不放失败箱，`UNASSESSABLE`/`ERROR`/`UNKNOWN_SEND`分别保留；不代选、不隐式重试。

本路线沿用原JM已验收的v3精确位置监测合同；不误接根包旧算法，不自动回退，不改变原边界/碰撞/支撑/stackable/包装承载保护，也不把面积分载余量与PCT反力互相回写。若后续发现监测或候选器问题，单独报告和立项，不与经验改进一起调到更好成绩。
