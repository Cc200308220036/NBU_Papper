# O3布局保留机制与消融协议

2026-10-19，开发期协议，在本轮validation运行前确定。已有validation和失败分析均已被查看；本轮不是新test，不作确认性统计结论。旧实验与执行器保持原样，buffer=1，物理生成器和Top-K=16不变，无模型调用。

## 研究问题与版本

区分三个因素：原软目标同分时的布局排序、明确允许软目标取舍带来的收益、在相同取舍预算下布局特征相对几何评分的增量。不能将新软政策收益解释为严格遵守旧政策时的算法改善，不能归因于Flash。

先运行一个已见train来源订单的接口试跑，再运行validation全部10来源订单×2政策×2执行模式×9变体＝360个episode。安全模式与业务观察模式分开报告；同一来源订单是统计簇。所有任务含提前终止，保留负结果。

## 9个变体

| 名称 | 策略 |
|---|---|
| original | 原公开Parser＋原Executor |
| strict_layout | 原业务与词典序最优等价集合内，用布局评分代替几何同分排序 |
| relaxed_geometry | 下述明确软预算集合内按原几何分选，控制目标放宽因素 |
| relaxed_full | 同一预算集合内平均四项布局评分 |
| relaxed_wo_floor | 删除地面形状评分，其余三项等权 |
| relaxed_wo_support | 删除同高支撑矩形评分，其余三项等权 |
| relaxed_wo_capacity | 删除顶面承载裕度评分，其余三项等权 |
| relaxed_wo_height | 删除垛高评分，其余三项等权 |
| relaxed_floor_only | 仅用地面形状评分，检查单指标是否足够 |

存在业务可行候选时只在其中选；安全模式无业务可行候选则终止。观察模式无业务可行候选时，先保留与原Executor相同的“最少新增/加重违规，再最少放后违规”层级，然后执行上述软排序。任何布局分不能抵消该硬层级。

## 新软政策预算

以**同一状态中原Executor所选候选**为锚点；每个候选在每项适用软质量上的损失不超过：`heavy_low=0.05`、`heavy_center=0.25`。对1200×1000×850mm托盘分别约为42.5mm重箱加权底高和195.26mm重箱加权中心距。两项同时约束，不是加权相互抵消；原动作始终保留在集合内。

预算是依据已见问题提出的开发参数，不是业务授权的工业阈值。本轮仅研究显式的新软政策；未来部署或正式test前需确认政策含义。此次不按validation结果搜索权重或预算。无适用重箱目标时保持N/A语义，不视为模型正确。

## 四项布局特征

仅使用当前箱、已放箱、容器及公开解析政策计算放置后的预测布局，不读取未来箱。

1. 地面形状：全高净空的最大矩形面积/托盘面积，与参考底面可容纳比例各占一半。
2. 支撑形状：对相同高度、暴露、可堆叠且至少留0.1H净高的顶面计算矩形质量，取最佳支撑层。地面不计为顶面。
3. 承载裕度：从位姿重建载荷，在暴露可堆叠顶面上按面积平均`min(1, 剩余允许承载/当前箱质量)`；剩余承载取物理上限与适用业务限载中较小者。
4. 高度：`1−最大垛高/H`。

参考底面固定为`(0.25L,0.25W)`、`(0.5L,0.25W)`、`(0.5L,0.5W)`，允许0/90度；它们是确定的几何探针，不是实际未来箱或训练订单统计。面积/适配比例只是代理，不保证后续物理可放性。完整评分四项等权，消融剩余项重新等权。候选同分仍按原几何分、公开编号确定。

## 验证与报告

报告每模式各变体完整放置、完整无违规、件数/体积比例、违规步骤、最终实例、原动作改变次数、软预算损失、物理违规与回放。原策略须重现既有对应validation结果。新runner保存公开请求、候选摘要、锚点/允许集合/特征评分、提议提交与终止，按初始场景和动作独立复算状态及业务量，并重新生成候选与重选验证。

先进行有物理/预算语义意义的单元测试和train接口试跑；通过后运行冻结validation。若实现错误，保留失败目录并新建输出版本，不在已有结果上覆盖或按表现调参。主比较为strict_layout−original、relaxed_geometry−original、relaxed_full−relaxed_geometry。逐来源订单配对差与区间仅作探索性分析，多项消融不作无校正的确认性显著主张。
