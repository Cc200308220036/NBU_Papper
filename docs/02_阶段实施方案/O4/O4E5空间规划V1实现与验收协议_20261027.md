状态更新（2026-10-27）：依用户要求，空间V1已从活动代码、配置和测试中撤回并归档；正式E5入口恢复到空间改进前版本。下文为历史实现/实验分析，不代表当前启用算法；其中空间V1运行命令不再适用于活动工作区。58条历史结果和评分不变。归档位于`semantic_pallet_planner/outputs/ARCHIVE_O4_E5_SPATIAL_V1_ROLLBACK_20261027_01/`。

2026-10-27。依据对齐候选与空间碎片分析新增独立规划版本`o4_e5_spatial_v1`，保持E2业务AST、物理提交、0°/90°、单箱/三箱缓冲及16/48/3/8/256预算。旧实现仍为默认，新增模块放在`o4/extensions/e5/spatial/`，E5原规划入口只增加显式配置分派。原始真实API实验和封存代码不覆盖。

## 1. 实现范围

候选模块复用E2同一个公开采样池，不增加基于私有参考或未来订单的采样。对已有池补全物理候选元数据后，优先保留4个相邻且边缘对齐代表、2个托盘边界代表、公共区域/朝向代表，再用旧候选及几何分补齐16个。配额去重并回填；保留/淘汰原因、区域、朝向及对齐方向均落盘。固定容量下可能损失其他方向/间距覆盖，必须在报告中列出。

空间评价使用10mm保守网格，在地面及实际箱顶水平面建立支撑/占用掩码。占用取并集；上层只计完整落在至少一个支撑面的格子，跨箱接缝可能低估。固定200×200、300×200、400×300mm底面探针允许0°/90°，枚举所有网格对齐位置；每类探针覆盖的格子只计一次，不因位置重叠重复累加。

评价项包括地面探针覆盖面积、地面未覆盖面积、边缘对齐数、上层探针覆盖面积和托盘边界接触数。它是几何潜力估计，不检查探针重量、业务类别和高度，不是实际未来箱体，也不是无解证明。小于探针的窄条可能仍有用，不能据此拒绝硬约束可行候选。

位置选择先沿用业务过滤和原重物低放/靠中软预算，再比较空间质量，最后使用旧几何分和稳定姿态顺序。没有把“总是靠左”写成业务规则；左右对齐的空间分应对称，几何完全相同的并列仍按稳定坐标顺序确定。

搜索仍优先路径件数、体积和高度，再比较同一空间质量；beam裁剪与最终路径选择保持一致。候选单独改进组保留原搜索排序，用于消融。没有提高深度、beam、后继预算。

## 2. 冻结的新实验

以既有E5真实结果的任务/配置为只读输入，按来源键排序取索引0、2、4，各C0/C1共6任务。所有方法共享同一来源、属性、规则及几何。

| 内容 | 数量 |
|---|---:|
| 6任务×4消融组×single | 24 |
| 来源02的C0/C1×4消融组×buffer_search | 8 |
| 6个原构造×combined×4规划器 | 24 |
| 来源02/C0×combined×Parser的single/search | 2 |
| 合计 | 58 |

四组为baseline、candidates_only、ranking_only、combined。源任务、构造、配额、探针、算法源码和job顺序在运行前冻结。先用Oracle明确规划差异，再以Parser核对代表订单；没有真实模型调用，不复用旧响应到新状态。来源仍是3个已知开发来源，不是独立泛化测试。

## 3. 验收标准

1. 旧默认路径选择、提交与缓存语义通过既有测试；旧E2及共享评分不改，E5只增加显式分派。
2. 来源00102047的固定第二决策点，对齐候选(-105,-240,0)进入16个候选；combined选择物理/业务可行的相邻边缘对齐位置，不要求强行选某一左侧坐标。
3. 网格并集不重复计面积，障碍不可跨越，镜像空间分一致；探针不覆盖仅作为评分，不能当硬拒绝。
4. 原硬业务、实际物理、守恒、状态绑定、候选摘要、未知朝向及预算边界继续有效。
5. 恢复、重复、公共几何缓存独立副本及确定性有测试；选择不读取未来订单或独立参考。
6. 冻结58条新实验完成、零实际违规、预算不越界；4个正构造完成、2个业务无解构造正确停止。
7. 报告四组完整结果、逐任务收益/退步、覆盖损失、运行成本和范围限制。局部对齐改善不自动等于整体完成率提高，是否替换默认版本依据实际效果另行决定。

本次验收不要求订单100%完成，也不安排旧240条额外复查。原E5离线全量复算豁免不因本轮局部规划开发改变。

## 4. 代码与版本

`spatial/config.py`冻结开关、探针和预算，`candidates.py`负责候选保留，`quality.py`负责几何平面评价，`planning.py`负责位置/搜索排序，`experiment.py`负责本地冻结实验与分母。配置文件为`configs/o4_e5_spatial_v1.json`，入口为`runners/o4_e5_spatial.py`；不存在remote选项。

后续算法、探针、配额或预算调整必须使用新的实验输出及版本记录，不能改旧结果。运行步骤与实际结果分别见后续运行手册及产出报告。
