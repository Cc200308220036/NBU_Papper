## 1. 唯一方案与版本边界

采用两层证据：**赋ID前的完整内容投影及影子核心 → proof → 最终ID与P → 最终影子绑定与publication**。不再让proof引用包含最终ID摘要的blob。原设计把发布影子的candidate_digest含义留空，是本次唯一整改点；不尝试哈希固定点，不删影子/派生证明。

## 2. 摘要的准确含义

符号C是现有contracts.canonical的UTF-8字节：JSON sort_keys、ensure_ascii=False、separators=(',',':')、allow_nan=False。L(x)=SHA256(C(x))，全64位hex；这是现有完整candidate_digest的定义，无额外摘要域，不改变它。B(blob)=SHA256(保存的原始字节)，不是重序列化后的SHA；geometry_blob_ref_v1严格仅version/sha256，路径不参与身份，解析后必须校验原字节。

新增摘要统一 H(kind,payload)=SHA256(C({"domain":"geometry_native_shape_identity_r1/"+kind+"/v1","payload":payload}))；不同kind不得互换。除下表明确排除的字段外，payload所有字段必需且无额外字段。摘要值不嵌入被摘要对象自身。版本字段也进入payload；对象的blob摘要B和语义摘要H都保存并分别验证，禁止以二者数值偶合替代校验。

内容类型树N用于content及所有新增H载荷内的原生数值：null→["NULL"]，bool→["BOOL",值]，str→["STR",值]，int→["INT",精确十进制文本]，float→["FLOAT64",大端8字节16hex]；list→["LIST",按原序N数组]，dict→["DICT",按键Unicode码点排序的[原字符串键,N值]数组]。非字符串键、非有限float和非原生类型拒绝。元数据中的版本、摘要、ordinal、路径等协议字段按其声明类型直接C编码，只有标记为native_tree的业务载荷应用N。该表示保留类型、负零和位模式，不改原profile或原blob序列化器。

## 3. 闭合字段及穿过blob的构造顺序

配套机器字段清单：[identity_contract_inventory.json](../../../semantic_pallet_planner/outputs/GEOM_CANDIDATES_GP5_NUM_N0_R1_20261117_01/identity_contract_inventory.json)。以下对象与nullable分支全部封闭，原字段类型/约束继承原清单；新增ref均geometry_blob_ref_v1。每个有ref对象还必须保存该对象的对应语义摘要；任何跨对象一致性由validator核对，不依赖JSON Schema单独证明。

1. 验证当前公开B_native/B_geometry、common/backend/config/source/environment，保存R、原generation字节；验证R完整原候选及原顺序，保存每个raw_candidate_digest。没有读取未来订单。
2. 从R[i]及源item形成仅尺寸原生叶子恢复的Q，先不赋最终ID；计算两侧content、source_dimensions、raw_size/target_size及逐轴证明。Q含除两身份字段外的所有候选字段。空池跳过逐项步骤，映射为空且原OK_EMPTY/input准入条件仍必需。
3. 保留原设计要求的两侧check_candidate、apply_candidate、派生/F0核对。这里仅规定后续实现：影子核心关联content身份，不需要最终ID。若原函数确实读取/传播candidate ID影响结果，后续实施必须停交QA，不能删字段或把差异藏入content投影。本轮没有运行这些函数。
4. 保存四个核心blob：两侧shadow_core全字段为version=geometry_native_shape_shadow_state_v3、side=RAW|PUBLISHED、ordinal、source_native_sha256、candidate_content_digest、placed_items。这里**不存在candidate_digest**。两侧derived_core按上表保存。refs先依赖核心字节B，不能指向下一步最终wrapper。equivalence保存四ref和四semantic digest、原全部物理/派生证明。proof_core保存equivalence；计算H(proof_core)。proof_core_ref只在后继保存，不写回proof。
5. 计算H(fingerprint)，赋P[i].candidate_fingerprint及GP5N3_ ID；重做内容投影必须等于published_content_digest，且P与R只有原允许三类改动。计算L(P[i])，保存P完整字节及池。最终P不是用影子after替换候选。
6. 每侧保存shadow_binding全字段：version=geometry_native_shape_shadow_binding_v1、side、ordinal、source_native_sha256、candidate_content_digest、candidate_digest、shadow_core_ref、shadow_core_digest、derived_core_ref、derived_core_digest、proof_core_digest。RAW的candidate_digest=L(R[i])，PUBLISHED的candidate_digest=L(P[i])；它明确保留“完整候选”含义。wrapper不复制/重新运行影子，不改核心blob。
7. 保存final_binding全字段：version=geometry_native_shape_final_binding_v1、ordinal、raw_pool_sha256、raw_candidate_digest、raw_content_digest、published_content_digest、proof_core_ref、proof_core_digest、published_candidate_id、published_fingerprint、published_candidate_digest、raw_shadow_binding_ref、raw_shadow_binding_digest、published_shadow_binding_ref、published_shadow_binding_digest。计算H(final_binding)。此对象只向先前对象引用，不进入proof/ID载荷。
8. ordered_mappings每行保留原ordinal/proof_ref/proof_digest/published ID/fingerprint/digest，增加raw_candidate_digest、raw_content_digest、published_content_digest、final_binding_ref、final_binding_digest；一R一P一行，同序满射且单射。拒绝重复ID、key碰撞、多对一、缺行/额外行，不过滤/去重。完成publication语义digest及blob，最后telemetry→audit→bundle/context→selection/action→monitor/commit/durable；所有后继都不能写回前件。

上述每个ref所指字节的字段都只依赖更早层。尤其 proof→equivalence→published_after_ref→shadow_core bytes→published_content，终止于Q；不存在full P/ID回边。final_binding→final shadow wrapper→full P→fingerprint→proof是单向链；proof不引用final_binding。四核心blob及最终wrapper均强制存在，不能只验证其中一套。telemetry被后继audit绑定，时间测量不进入candidate身份。

## 4. 保存验证、拒绝规则及可信边界

验证器从已冻结durable/bundle的publication摘要出发，验证整个可达引用闭包；按第1—8层重算字节SHA及语义摘要、三轴证明、内容投影、fingerprint、ID、完整候选摘要及全部跨字段相等关系。source pointer须解析到同一B_native当前pending项，ordinal及backend/common binding须一致；两侧wrapper的content摘要必须等于从完整R/P重算所得，candidate_digest必须等于完整R/P摘要；wrapper必须指向proof中**同一侧同一ordinal**的核心/派生refs和摘要。final_binding及mapping/publication必须与这些值完全一致。全部验证完成前不得发布可选bundle或继续选择/monitor/commit。

缺任一R/P/proof/core/derived/wrapper/final_binding/publication blob，报NUM_BRIDGE_MISSING_ARTIFACT；字节SHA、域、版本、source/config/backend、side/ordinal、签名、完整摘要或跨引用不一致，报NUM_BRIDGE_IDENTITY_MISMATCH；完整双射失败报NUM_BRIDGE_MAPPING_INVALID。未知字段、混合版本、只存PASS、篡改未转换字段、交换raw/published或不同候选/不同prefix证据，一律技术拒绝；不得补件、重签、重新发布/桥接、隐式重试或恢复历史坏前缀。

仅改blob不改ref会在B失败；换blob及ref但不改proof在proof摘要失败；同时重算下游会改变fingerprint/P/publication，必须与冻结durable/selection/action根比较而拒绝。若攻击者可替换全部材料及可信根，普通哈希不提供签名或真实性保证；不能声称该方案能认证伪造物理结果。SAVED只验证已存证据/精确数值证明，不重新跑影子物理；原共享已选转移恢复核验独立保留。FRESH原物理/派生检查全部仍强制，元数据一致不构成其PASS。
