## 3. 数据流、持久化、恢复与身份

管理员准入 → 冻结plan/源码/配置/依赖/数据 → 单job execution绑定 → 公共initial/receive → 当前公开state/observation → 同源B_native/B_geometry及common binding持久化 → 两后端各按冻结配置生成 → bundle/audit/F0侧车落盘 → DECISION_READY → 独立本地选择 → SELECTED持久化 → 独立副本监测精确已选动作 → MONITORED持久化 → STABLE调用原commit_physical一次 → COMMITTED持久化 → 评价/事件与汇总 → 完整订单终止。

共用`geometry_runtime_shortest_decimal_v1`；native保留类型/float位模式/顺序，geometry按repr十进制Fraction逐叶导出。共同准入先于后端生成；精确前缀冲突技术停止，不改坐标/容差。生成ERROR不变空池，不输出部分池或切后端。原面积分载与PCT反力账本分离。单候选同样走选后监测，无预过滤/改选。

| 状态/故障 | 必须行为与恢复 |
|---|---|
| DECISION_READY | 复用已存bundle/F0，不重复生成；允许尚未发生的首次本地选择 |
| SELECTED | 不重选，仅完成尚未保存的监测；监测发送不涉及网络，结果不明技术停止，不靠重试掩盖 |
| MONITORED/STABLE | 复用原结果，不重评，仅提交尚未提交的动作 |
| COMMITTED | 不再commit；仅续评价/记账，继承R1评价失败严格关系核验 |
| STABLE后提交错误 | GEOMETRY_COMMIT_TECHNICAL_ERROR终态，继承R1只读恢复，不自动再放箱 |
| UNSTABLE | PREDICTED_STATIC_INSTABILITY；失败箱不放、不移缓冲、不加装入量；停止该job，无第二选择 |
| UNASSESSABLE / ERROR / DISABLED | 分别STABILITY_UNASSESSABLE / STABILITY_MONITOR_ERROR / 禁用错误；均不提交。GP5要求enabled=true，禁用不记稳定 |
| 输入/预算/存储/Schema/身份错误 | 技术失败停止；无摘要重签、缺件重建、输入默认化、隐式重试 |
| 取消/管理中断/未运行 | 独立状态保留在8job分母；不能作为正常订单失败或从分母删除 |

blob先临时写+fsync+atomic replace+目录fsync+读回，再发布checkpoint引用；checkpoint先内部持久化再callback。恢复在私有副本校验before→after，用原buffer.place核对不计真实再次commit，不执行候选/选择/内核。恢复冻结同一config/data/task/source/physical/generator/selector/monitor/profile/环境及依赖；源码新增py/json本身也可能改变宽范围身份，旧运行须拒绝，绝不重签旧checkpoint。

身份清单须列所有生产py/json集合（不仅旧physical_manifest）、后端配置/预算、prompt/F0/种子构造、runtime适配、Schema、monitor exact算法/配置/依赖（Python、求解器及版本）、序列化环境及数据原件。freeze只在获后续有限真实验收/运行授权时进行；本准备包仅保存只读SHA，不执行exact_freeze。

## 6. 完整订单指标与负例分母

GP5必须event_limit=None且关闭smoke前缀入口；到货必须耗尽并有EOS或明确合法停单，summary/phase/reason核对一致。管理超时/事件保护触发记技术中断或取消，不能填ALL_ITEMS_PLACED。8job即使失败/取消/未启动全部列出；每个配对必须两侧状态齐全，不只报告成功分母。

| 指标 | 合同及现有实现边界 |
|---|---|
| 完成、装入件/体积/质量比例 | 分母为原完整task，失败箱不计入；packaging_runtime.summary已有基础字段，新增v16输出注册 |
| 固定容器利用率 | sum(已装定向体积)/(L×W×Hmax)；当前summary未直接输出该字段，拟新汇总显式计算；不能用placed_volume_ratio代替 |
| 垛高、包络利用率 | 垛高=max(z+h)；包络=sum已装体积/((maxx-minx)×(maxy-miny)×垛高)，z自地面0，空垛NA；当前summary包络NOT_IMPLEMENTED，后续实现或明示缺失，绝不伪0 |
| 预测静态失稳进度 | 首UNSTABLE前已装件/体积/质量比例、失败decision/箱/精确动作及monitor记录；非真实坍塌率 |
| 分类分母 | ALL_ITEMS_PLACED、正常无物理候选、PREDICTED_STATIC_INSTABILITY、UNASSESSABLE、内核ERROR、输入/生成/提交/存储/评价技术失败、取消、NOT_RUN分别列明 |
| 时延 | 每步生成、公共准入/F0、选择、真实monitor、提交、checkpoint/评价及job总墙钟；缓存命中按真实backend，不冒用E2缓存；少量job只列原值/中位/最大，不做显著性推断 |
| 成本与调用 | 实际选择、singleton、monitor入口/真实LP、恢复增量分别计；本地无服务发送，服务费用NA_NO_SERVICE_CALL；不可得成本UNKNOWN。旧summary固定0不自动表示新协议费用语义已验收 |

装入量优先，同装入量再看布局；技术错误/不可评价不强行排名。全部装入时固定容器利用率相同不证明布局更优，剩余承载总和不等于未来可装件数。原公共硬检查零违规不是策略创新。限定同源训练比较不证明Jev、未见泛化或全局最优，不要求新后端获胜，不因负结果修改冻结算法。
