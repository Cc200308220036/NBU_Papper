## 实现与协议

| 接口 | 实际行为 |
|---|---|
| `freeze_start` | 绑定父receipt及其文件摘要、snapshot/task路径与JSON指针；各文件须被对应receipt列举。保存原snapshot完整字节身份，任务与起点语义交叉核对；不创建候选。 |
| `validate_start` / `validate_binding` | 重读保存字节，核对task、前状态、cursor、已到货序列、缓冲、EOS、完整池、显示映射、原动作及config/策略身份。重新计算外层摘要不能遮盖内容篡改；不派发执行。 |
| `bind_branch` | 只接受保存池已有标签，绑定新branch ID、不可变candidate ID、完整候选与精确action。按原动作、同箱不同位置/朝向、跨箱分类；不自动采点、排序或挑分支。 |
| `bootstrap` | 深复制原前状态、到货cursor、缓冲、完整池和映射，仅重新绑定子job/decision身份，创建新的SELECTED检查点；父task/config/checkpoint不修改、不重签。 |
| `run_forced_first` | 要求保存回调；沿公共`run_episode`保存SELECTED，再监测、保存MONITORED；STABLE调用原`commit_physical`一次，失败分类停止；成功首步结束立即停止在`JM_CONTINUATION_NOT_IMPLEMENTED`。 |

强制选择来源为`FORCED_FROM_FROZEN_POOL`，记录`forced_action_count=1`、`model_call_count=0`、`network_attempted=false`、空attempt IDs。不使用旧v5包络或test_double来源伪装强制动作；原v6/v12候选、上下文和检查点包络作为原样适配层保留，新分叉绑定和选择凭据独立版本化。旧`packaging_counterfactual.py`常量、bootstrap、几何后续和保护原样保留。

A1执行入口仅接受`CONSTRUCTED_ONLY`起点；归档材料使用`ARCHIVED_ONLY_NOT_EXECUTION_ADMISSION`，bootstrap拒绝执行。公共路由要求未实现后续哨兵和保存回调，拒绝用户传入的替代selector；传入resume明确拒绝`jm_resume_not_implemented_A3`。因此没有几何或经验后续回退，也没有真实Jev后续工厂/发送账本。即使首步恰好放完最后一箱，也保留A1边界停止，不称整单自然完成。
