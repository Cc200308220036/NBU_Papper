| 接口 / 版本 | 行为 |
|---|---|
| `freeze_execution` / `validate_execution`，`jev_jm_recovery_v1` | 从不可变 A1 binding 派生重复 job，冻结原 branch、repeat_slot、精确动作、task/config、源码/依赖/策略、监测及逐槽位预算。保留 A2 `jev_jm_no_memory_policy_v1` 和构造范围限制。 |
| `freeze_schedule(rows, root=...)` / `validate_schedule`，`jev_jm_repeat_schedule_v1` | 显式注册全部 branch/slot 和预算总和，固定仓库相对存储根；同 branch/slot 重复登记拒绝，换目录执行同计划拒绝，未注册槽位拒绝。重复不是新增起点或来源。 |
| `RecoveryLedger`，`jev_jm_recovery_requests_v1` | 独立 execution 锚点、context/body、`jev_jm_recovery_reservation_v1` 和请求状态。`admit_send` 对新请求和恢复 INTENT 都检查全账本停止、当前冻结身份和预算，再允许首次发送。 |
| `selector_factory` / `validate_route` | 使用原 selector 及 Choice 解析；只接受 `CONSTRUCTED_FAKE_TRANSPORT`、`origin=test_double`，不读取凭证，不创建 transport。 |
| `run_repeat` | 在冻结根与确定的 allocation 子目录内执行或恢复；全计划独占写锁拒绝并发重入，不复制订单引擎。保存 `DECISION_READY` 后才进入 selector。 |
| `jev_jm_activation_v1` / `jev_jm_recovery_checkpoint_v1` / `jev_jm_checkpoint_journal_v1` | activation 原子保存初始强制 SELECTED；后续检查点有连续序号、前项摘要和独立尾部摘要。封闭 Schema 独立新增，旧 v6 检查点不接受新版本。尾部缺失、缺口、损坏或摘要不符时拒绝。 |

保存校验只核对保存状态、身份与链路，不重放已提交前缀，也不使用物理提交来证明保存事实。阶段校验的事件去重缓存仅存在于单次调用中，以完整事件摘要为键；变更字节重新校验，不跨调用缓存源码/依赖身份。外层 Schema 与内层 execution/checkpoint 都各自验证。

## 恢复语义与停止门

| 保存事实 | 恢复行为 |
|---|---|
| activation 已建立 | 复用其中原子保存的强制 SELECTED；尚无请求时初始化新账本。 |
| `DECISION_READY` / context 已保存、无 INTENT | 复用保存 observation、pool、mapping、body；完成尚未写入的预约后，满足发送门才首次发送。 |
| reservation 已保存 / `INTENT` | 校验相同身份，不新增预约或重复消费预算；只有安全未发送 INTENT 可以发送。 |
| `SENDING` | 通过原请求状态机转 `UNKNOWN_SEND`，订单保留 `UNKNOWN_IN_FLIGHT`，不推断未发、不重试。 |
| `RESPONSE_SAVED` | 复用原响应继续原 Choice 解析，不重新发送。 |
| `SELECTION_SAVED`，但公共 SELECTED 尚未落盘 | selector 读取账本原选择，不重新发送或重新解析已有选择。 |
| 公共 `SELECTED` | 不调用 selector；首次监测。 |
| 公共 `MONITORED` | 复用原监测及凭据；STABLE 才首次提交，各失败状态分类停止、不改选。 |
| 公共 `COMMITTED` | 只完成公共选后评价和追加原事件，不再提交、监测或选择。 |
| `READY` / `TERMINATED` | 继续尚未发生的下一步，或返回保存终态；不重新强制首步、不追加重复决策事件。 |
| 身份漂移、预期记录缺失、损坏 | 拒绝；不修复摘要来迁就当前源码。非原子多文件写入形成不一致时保守拒绝，不声称任意文件系统故障都能自动续行。 |

**QA-JM1A2-01**：新增发送门复用 A2 全账本停批检查，覆盖原 `RequestLedger` 已有 INTENT 的 matches 路径。构造“先保存 INTENT，再让另一请求实际形成 UNKNOWN_SEND 或 FAILED”，再恢复首条 INTENT，确认发送门拒绝、原 INTENT 不变、transport 仍只有前一条已发生的调用。安全 INTENT 的无停止恢复另由中断矩阵覆盖。A2 历史实现未改签为已通过 A3。

预算按每个已注册槽位独立消费。原动作、同箱换位和跨箱绑定保持精确干预身份并共享策略，不承诺后续随机结果相同。相同计划不能换输出根重复执行；调用方须保留原冻结根和完整记录。没有覆盖外部删除全部记录、恶意重建另一计划或跨机器复制多份执行的全局恰好一次承诺；SENDING 未知始终停止。
