## 最小实现

- 从保存事件与当前 pending_event 建立非强制 CHOICE_REQUIRED 决策集合。每份 context 必须属于该集合，且内容与该保存事件的 context 相同；reservation 继续受原 context 子集及预约身份等值检查保护。
