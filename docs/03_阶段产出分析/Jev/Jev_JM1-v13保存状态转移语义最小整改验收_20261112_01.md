## 实际改动与字段规则

`validate_saved_checkpoint` 继续作为 `validate_saved_execution` 和 `run_execution` 恢复前门的共同校验。新增 `validate_saved_arrival` 与 `validate_saved_place`；接口签名及规则记录于 `interface_receipt.json`。运行协议和Schema版本不变，只补齐既有合同的拒绝条件；源码摘要随改动更新，旧执行身份不改签。

| 转移 | 唯一允许的变化 |
|---|---|
| WAIT_RECEIVE | 前态未EOS且缓冲有空位；取冻结task当前arrival_count项，完整item及attributes等值；分配最小空槽，arrival_index等于原cursor；按顺序追加pending/arrived_ids/attributes；arrival_count与event_index各加1，其余状态完全不变。 |
| EOS | 当前cursor恰为任务长度且允许到货；仅end_of_stream变true、event_index加1；箱体、属性、几何、容器和其他计数不变。 |
| PLACE新增箱 | 必须为已选缓冲箱的完整内容，叠加候选精确pose/yaw/oriented_size；朝向尺寸同时对应原箱0/90尺寸；新supported_load为0，support_fractions按保存几何面积推导。 |
| PLACE原状态 | 按顺序移除所选pending条目；其余缓冲条目和槽位完整不变；placed_count与event_index各加1；容器、attributes、到货列表/cursor、EOS及其他字段不变。 |
| PLACE旧已放箱 | 所有字段完整相等，只有supported_load_kg可以按确定的面积分载增量更新；旧support_fractions、位姿、尺寸、质量和包装属性不能随ID相同而变化。 |

面积分载审核使用既有 `geometry_oracle.bounds/support_rect/propagate` 的纯算术：由所选保存足迹与旧箱顶面求接触面积，按面积比例分配本箱质量，再沿已保存且已验证的旧支撑边传播；比较每个旧箱的精确更新值。保留既有面积规则的接触容差和遍历顺序，没有引入新物理容差或监测算法。新辅助函数不调用receive、place、apply_candidate、commit_physical、候选器或LP，不重放历史前缀。

完整保存validator仍保留原有context一致性检查：该公共检查会在副本上调用既有 `apply_candidate` 计算候选公开特征。这是原有纯特征算术，不是生成候选、重放历史轨迹或派发真实提交；本次没有削弱该检查，也不将其描述为整个validator从不执行任何候选特征计算。

## 生产入口反例与正例

定向测试 `test_packaging_jev_v13_saved_transitions.py` 保存一套正常基线阶段记录及一套合法堆叠记录。对正常根逐次改变一个journal中的after内容、同步checkpoint.state并重封局部摘要；任务/配置/执行身份保持不变。完整链其余文件不改，校验应在处理该条转移时拒绝，而非靠后续head或链摘要不符代替值级校验。每次检查后还原原始journal字节，再核对整个原根身份。

生产入口为 `validate_saved_execution` 和 `run_execution` 恢复入口。36类负例各执行两次：

- 到货质量、尺寸、包装属性、槽位、arrival_index、到货ID、cursor、原缓冲内容、容器、event_index及EOS标志。
- EOS时缓冲载荷、旧箱几何、结束标志、容器及attributes变化。
- 新放箱位姿、朝向、oriented_size、原尺寸、质量、承载属性、stackable、初始载荷及支撑边变化。
- 剩余缓冲内容或槽位、旧箱位姿/质量/尺寸/承载属性/载荷/支撑边，以及PLACE容器、attributes或event_index变化。

其中33类命中新增arrival/place值级拒绝，另3类到货index/ID/cursor结构损坏由原buffer_invariant拒绝。质量与位姿两类对应父静态见证，本轮在当前新身份构造材料上实际拒绝；不改写父QA的NOT_RUN事实。

测试拦截模型transport、decision_inputs、monitor、commit_physical和receive，另继承禁止网络、凭证、候选器、v3/v2求解、MemoryDriver的构造fixture保护。72次检查的派发计数全0；每次两入口之后，损坏文件及其余保存文件字节均未改变，原正常根最终恢复原字节。原始损坏journal与逐例拒绝收据保留，供独立质检核对具体错误。
