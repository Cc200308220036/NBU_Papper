# O3布局保留机制开发与消融结果

2026-10-19。本文记录失败归因后的“步骤2：布局保留机制开发与消融”。原始O3运行器、执行器、候选器和历史产物保留，新实现以独立模块与新实验目录运行。没有模型调用，没有改变buffer=1。

正式结果目录：`EXP_OPT_O3_LAYOUT_VALIDATION_20261019_01`。来源为原validation的10个独立订单，每单P0/P1双政策，9变体×2模式，共360个episode。本批订单、政策与失败已用于开发，**不是独立新test**。

## 1. 核心结论

已实现四项布局代理、严格同分策略、显式软预算策略及完整消融框架。当前结果支持继续研究支撑/承载/高度保留，但**不支持“完整四项布局评分优于原几何评分”**。

1. 严格同分布局排序使完整无违规从7/20下降至6/20；同分动作可以改变后续轨迹，但当前排序没有稳健改善。
2. 在明确允许有限软目标取舍后，仅用原几何评分，观察模式放完任务从11/20增至18/20；该变化包含目标放宽，不能归因于新布局特征。
3. 同一预算下，完整四项评分仅放完13/20，低于几何对照18/20；两者完整无违规都为8/20，完整评分的平均放置比例也更低。
4. 删除地面项的变体`relaxed_wo_floor`，本批安全模式完整无违规12/20；观察模式放完18/20、完整无违规12/20、最终违规实例15。它是开发期候选，不是已经证实的新最优算法，也未替换默认策略。
5. 该候选仍有明显失败：SCN_0060/P0、P1仅放7/17；其观察模式平均件数放置比例94.12%，低于几何预算对照99.41%。不能只看12/20的成功数。

## 2. 实现与实验协议

运行前已确定[消融协议](../../02_阶段实施方案/O3/O3布局保留机制与消融协议_20261019.md)，冻结参考矩形、等权评分和软预算，未按本轮validation结果重新调参。train先完成1来源订单×2政策×4核心变体×2模式＝16个episode的接口试跑，正式目录为`EXP_OPT_O3_LAYOUT_TRAIN_20261019_02`；`_01`保留为回放检查扩展前的首轮试跑。

| 实现 | 作用 |
|---|---|
| [evaluation/layout_preservation.py](../../../semantic_pallet_planner/src/semantic_pallet_planner/evaluation/layout_preservation.py) | 从当前预测布局计算地面形状、同高支撑矩形、承载裕度和垛高；不读取未来物料 |
| [selectors/layout_preserving.py](../../../semantic_pallet_planner/src/semantic_pallet_planner/selectors/layout_preserving.py) | 保留原业务层级，选择严格同分或显式预算允许集合；记录原锚点、损失及候选评分 |
| [runners/layout_ablation.py](../../../semantic_pallet_planner/src/semantic_pallet_planner/runners/layout_ablation.py) | 两执行模式×9变体在线闭环、原始轨迹、聚类比较、完整回放与历史基线核对 |
| [scripts/report_layout_ablation.py](../../../semantic_pallet_planner/scripts/report_layout_ablation.py) | 只读已保存轨迹，生成预算复核、逐来源表、变化动作表与图像 |

### 2.1 严格与有限取舍必须分开

`original`直接调用原Executor。`strict_layout`只在原业务可行且词典序最优等价集合中调整排序，不放宽软目标；观察模式无业务可行候选时也保留原最少增量违规、最少放后违规及严格软排序层级。

`relaxed_*`采用新的实验软政策：相对同一状态下原Executor候选的质量，`heavy_low`最多损失0.05，`heavy_center`最多损失0.25；对当前托盘约对应42.5mm重箱加权底高、195.26mm重箱加权中心距。两项分别约束，不互相抵消；原动作始终可选。

预算是实验协议与manifest中的新增决策配置，不是模型从原指令推断出的许可，也不是工业部署阈值。基础自然语言政策及AST仍保留，用于锚点和损失计算；不能把有限取舍变体写成严格满足原词典序软最优。物理和业务硬层级始终先于布局评分。

### 2.2 布局特征

四项均归一到0—1：

- 地面：全高净空最大矩形面积比例与固定参考底面适配比例各占一半。
- 支撑：暴露、可堆叠、同高度且保留至少0.1H净高的完整矩形质量，取最好的支撑层。
- 承载：独立重建载荷，按顶面面积平均剩余允许承载相对当前箱质量的比例，上限为1；同时考虑物理承载与公开业务限载。
- 高度：1减最大垛高/托盘高度。

参考底面为`0.25L×0.25W`、`0.5L×0.25W`、`0.5L×0.5W`，允许0/90度旋转；不是实际未来箱。完整评分四项等权，删除某项后剩余项重新等权。它们是代理指标，不能证明未来可放，也未完整建模悬空箱下方空间、70%部分支撑或间接承载瓶颈。

## 3. 安全模式结果

每方法20政策任务，独立来源10。所有提交均保持业务硬合规，因此本模式放完数与完整无违规数相同，已提交业务违规均为0。

| 变体 | 放完且无违规 | 平均件数放置比例 |
|---|---:|---:|
| original | 7/20 | 70.47% |
| strict_layout | 6/20 | 71.94% |
| relaxed_geometry | 8/20 | 88.40% |
| relaxed_full | 8/20 | 81.25% |
| relaxed_wo_floor | 12/20 | 86.43% |
| relaxed_wo_support | 8/20 | 81.75% |
| relaxed_wo_capacity | 8/20 | 81.75% |
| relaxed_wo_height | 9/20 | 83.61% |
| relaxed_floor_only | 7/20 | 83.06% |

`strict_layout`的放置比例略升，却损失了SCN_0058/P1的整单成功：原策略17/17，严格布局排序16/17。这再次说明平均放置比例与完整成功必须共同报告。

完整四项评分与几何预算对照成功数相同，但平均件数放置比例低约7.14个百分点；不能将其相对原策略的改善全部归因于四项特征。

## 5. 消融带来的解释与反例

### 5.1 为什么不能直接保留完整四项评分

地面大矩形/参考底面指标可能在首箱就支配朝向和位置。例如SCN_0054/P1：完整评分首箱选择`(515,-310,z=0,yaw=90)`，最大地面矩形1,030,000mm²；去地面项选择`(410,415,z=0,yaw=0)`，最大矩形996,000mm²。首箱尚无适用重箱软目标，其他三项同分，于是地面项的小幅差异改变了整个后续轨迹。

这个案例中“更大净空矩形”并未对应更好的整单结果：安全模式完整评分12/17，去地面项17/17。该证据指向当前代理与长期目标不一致，不能据此断言所有地面保留指标都无用。

![0054/P1最终布局对照](../../../semantic_pallet_planner/outputs/EXP_OPT_O3_LAYOUT_VALIDATION_20261019_01/figures/O3_SCN_0054_P1_final_layouts.png)

删除一项同时提高其余项归一化权重，因此“去地面项更好”是该版本的配置消融结果，不是地面因素的普适负效应证明。

### 5.2 改善集中在少数来源订单

`relaxed_wo_floor`相对原策略新增5个完整无违规政策任务：0051/P0、0051/P1、0054/P0、0054/P1、0057/P0，没有损失原有7个完整无违规任务。这些新增成功仅来自**3个独立来源订单**。

其余失败也必须保留：安全模式0052双政策停在7/8、0053双政策停在15/19、0056双政策未完成、0060双政策停在7/17。观察模式则仍在0060双政策停在7/17。当前结果不足以说明策略跨新订单稳定有效。

### 5.3 原失败的改善不全来自新布局特征

0052/P0、P1在观察模式中，几何预算对照和完整布局评分都恢复8/8，但仍有业务违规。0057/P0则二者都恢复完整无违规。把这些改善全部称为四项布局机制的收益，会混淆“允许偏离居中软偏好”和“新的代理排序”的作用。

同理，strict_layout没有预算放宽，却丢失0058/P1的无违规整单成功。应继续保留它作为严格政策对照，不能因结果不佳从论文表中移除。

## 6. 配对区间与研究结论

按每个来源订单平均双政策差值，再进行5000次固定种子bootstrap。以下均为本批已见开发数据的探索性区间，未作多重比较校正，10个来源簇仍很少。

| 比较 | 指标 | 差值 | 探索性95%区间 |
|---|---|---:|---|
| strict_layout−original | 安全模式完整无违规 | −5个百分点 | [−15, 0]个百分点 |
| relaxed_geometry−original | 观察模式完成 | +35个百分点 | [+15, +60]个百分点 |
| relaxed_full−relaxed_geometry | 观察模式完成 | −25个百分点 | [−55, 0]个百分点 |
| relaxed_full−relaxed_geometry | 观察模式平均件数比例 | −7.25个百分点 | [−14.90, −1.00]个百分点 |
| relaxed_wo_floor−original | 完整无违规，两模式相同 | +25个百分点 | [0, +55]个百分点 |
| relaxed_wo_floor−relaxed_geometry | 完整无违规，两模式相同 | +20个百分点 | [0, +50]个百分点 |

成功率改善区间包含0，且该较好变体从多项消融中被识别；不能以25个百分点样本差直接宣称已获得正式显著增益。预算几何对照的完成改善也包含任务目标变化，不能替代原严格政策下的算法对照。

本轮研究判定：严格同分布局排序未支持收益；完整四项评分相对相同预算几何控制未支持收益；去地面项是值得在独立开发来源验证的候选；VLM、视觉及动态记忆收益均未测试。

## 8. 下一阶段建议

保留原默认策略和本轮全部消融，暂不将完整四项评分作为主方法。下一轮应在新的独立开发订单中预先固定比较`original`、`strict_layout`、`relaxed_geometry`、`relaxed_wo_floor`，验证本批现象是否复现；预算强度、参考尺度和0.1H净高需要做预先声明的敏感性分析。

针对0060等残留失败，优先研究带长宽/高度/承载条件的空间可放性代理，而不是继续增加通用面积权重。若引入训练分布虚拟箱探测，应固定分布、计算预算，并对强基线提供相同信息；不得读取实际未来到货箱。

本轮已经把“目标取舍”和“布局代理”分开，可作为下一阶段独立验证的基础；仍不足以冻结正式论文test，也不构成进入远程Flash实验的增益证据。
