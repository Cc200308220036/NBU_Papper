## 2. 数值修复范围

新增[layout_preserving_v2.py](../../../semantic_pallet_planner/src/semantic_pallet_planner/selectors/layout_preserving_v2.py)，没有修改 V1 布局模块、特征模块、原 Executor、候选器、物理检查或旧运行器。

- 原控制 `original` 及软预算锚点继续调用冻结的原 Executor。
- `relaxed_geometry` 在原允许集合内做稳定的几何排序。
- `relaxed_wo_floor` 使用原 support/capacity/height 三项特征，均值改用 `math.fsum`。
- 先求布局分最大值 M，保留 `score >= M−1e-12`，再在保留集合中按几何分最大值和相同范围筛选，最后按公开 Cxx 标签选择。
- 不用成对近似相等比较，避免 A≈B、B≈C 时错误地把 C 当作接近最大值 A；不按浮点原值的微小差距抢先选址。
- 1e-12 是固定的无量纲排序精度，未根据新矩阵效果调节。它不改变业务 EPS=1e-6、物理判定或 `heavy_low=0.05`、`heavy_center=0.25` 的原预算。

版本标识：`layout_preserving_v2_fsum_max_anchor_1e-12`。它是明确的新排序政策，不假装精确复现有数值缺陷的 V1 布局策略。
