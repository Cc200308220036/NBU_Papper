2026-10-21。两项 V2 真实实验均已完成并验收 **PASS**；本次重新只读回放也均为 PASS，全部 Parser 轨迹匹配已认证的 V2 离线基线。此前 V1 的历史排序不一致没有在本次 V2 中重现。

### 原始 AST 并非全部结构相同

一致率文件中的 `ast_equal` 比较的是当前状态解析后的有效政策。独立检查发现：

- B：507 个普通 AST，1 个条件 AST。
- C：1450 个普通 AST，52 个条件 AST。
- 全部 53 个条件 AST 的 then/else 分支均相同，且都与对应 Parser 政策一致。消去这种冗余条件后，完整政策语义也全部一致，没有未执行分支中的隐藏规则差异。

因此，准确表述是“有效政策和动作 100% 一致”，不能写成“所有原始 JSON/AST 结构完全相同”。这些冗余包装也不能作为条件推理或动态政策能力的证据。

### 对模型贡献的结论

当前收益由相同 AST 下的执行器排序产生。Flash−Parser 的完成、无违规完成、放置比例及最终违规实例差均为零。2000 余次请求反复解析 P0/P1 两套固定政策，并不等于测试了 2000 种独立语言表达。

可以声称本轮真实服务解析与确定性执行器能够稳定协作；不能声称 Flash 优于强 Parser、已证明视觉贡献，或已验证政策切换与自然语言泛化。当前无需再扩大相同固定文本的付费重复调用。

### 安全模式

相对原策略，软预算＋几何控制平均件数比例提高 17.93 个百分点，但完整无违规任务仅增加 1 个。去地面项增加 5 个完整无违规任务，平均件数比例提高 15.96 个百分点。

同预算下，去地面项较几何控制多完成 4 个任务，但平均件数比例低 1.97 个百分点。因此“更多整单成功”和“更高平均放置进度”仍是不同目标。

### 业务观察模式

几何预算控制将完成率从 55% 提高到 90%，但无违规完成率仅从 35% 到 40%，最终违规实例从 29 到 30。这部分收益包含明确的软目标取舍，不能归因于模型，也不能描述为业务约束全面改善。

在同预算下，去地面项维持 90% 完成率，将无违规完成率从 40% 提高到 60%，最终违规实例从 30 降到 17。但其平均件数比例从 99.41% 降到 94.12%，不能宣称全面占优。

### 改善来自哪些来源

相对原策略，去地面项两模式均新增以下 5 个无违规完成任务，没有丢失原有无违规完成任务：0051/P0、0051/P1、0054/P0、0054/P1、0057/P0。它们来自 **3 个来源订单**，不是 5 个完全独立样本。

几何预算控制新增的无违规完成任务只有 0057/P0。去地面项相对几何控制的四个新增无违规完成任务来自 0051、0054 两个来源。

## 5. 违规降低是否只是少放箱子的结果

观察模式两个改进方案完成的是完全相同的 18 个任务，均只剩 0060 双政策未完成。因此可以对相同完成任务进行描述性拆分：

| 同一任务集合 | 几何预算控制 | 去地面项 |
|---|---:|---:|
| 完成任务数 | 18 | 18 |
| 这批任务提交件数 | 250 | 250 |
| 这批任务无违规完成 | 8 | 12 |
| 这批任务违规步 | 25 | 21 |
| 这批任务最终违规实例 | 25 | 17 |
| 失败的0060双政策提交件数 | 32 | 14 |
| 失败的0060双政策违规步 | 4 | 0 |
| 失败的0060双政策最终违规实例 | 5 | 0 |

最终违规实例总减少 13，其中 **8 个来自相同完成任务上的布局改善，5 个来自失败订单放置进度/暴露不同**。违规步总减少 8，其中完成任务减少 4，失败任务减少 4。

这说明业务改善不全由少放箱子造成，但全体违规率仍受到放置数量影响。该拆分用于解释结果，不是新预注册假设，也没有额外进行子集显著性检验。

条件违规指标也需联合完成率阅读：原策略完成任务中最终违规率为 4/11=36.36%，几何控制为 10/18=55.56%，去地面项为 6/18=33.33%；全部计划任务曾出现违规步的比例分别为 9/20、12/20、6/20。

## 6. 仍然存在的失败与负结果

- safe 原策略有 13 个失败：9 个业务可行集合为空、4 个无物理候选。
- safe 几何预算控制有 12 个失败，全部为业务可行集合为空。
- safe 去地面项有 8 个失败：6 个业务不可行、2 个无物理候选。
- observe 两个改进方案均剩 0060/P0、0060/P1 无物理候选终止：几何控制各放 16/17，去地面项各放 7/17。后者少放的 18 件恰好解释观察模式两方案提交步 282 与 264 的差距。
- 0056/P1 去地面项虽已完整放完，仍有最终违规实例 4、违规步 6；布局代理没有消除长期业务损害。

无物理候选与业务可行集合为空是当前状态下的局部终止，不证明整个订单无可行解。物理违规为零也不表示观察模式业务违规为零；观察模式按冻结协议在业务无解时继续最小伤害选择。

## 7. 统计解释与结论边界

C 文件中的区间采用十来源订单聚类 bootstrap，先平均双政策差值，未作多重比较修正。关键探索性结果：

| 对照与指标 | 均值差 | 探索性95%区间 |
|---|---:|---:|
| 观察：几何预算−原策略，完成率 | +35 个百分点 | [10,60] 个百分点 |
| 安全：几何预算−原策略，平均件数比例 | +17.93 个百分点 | [5.50,31.96] 个百分点 |
| 同预算：去地面项−几何，无违规完成率（两模式） | +20 个百分点 | [0,50] 个百分点 |
| 安全：去地面项−几何，平均件数比例 | −1.97 个百分点 | [−12.23,5.35] 个百分点 |
| 观察：去地面项−几何，平均件数比例 | −5.29 个百分点 | [−15.88,0] 个百分点 |
| 观察：去地面项−几何，最终违规实例/episode | −0.65 | [−1.50,0.10] |

不能把接触零的区间表述为已建立稳健显著优势。去地面项此前经过消融选择，十来源也已经反复查看；本轮仍是开发证据，没有消除方法选择偏差。Flash 与 Parser 对照各项差值为零，不是模型增量成功。

数值修复后的正确 V2 观察口径为 **违规步21、最终实例17**。旧布局的18/15、旧V1 C的18/16不能替代本轮数据。旧V1 C的FAIL和V2 C的PASS均保留，各自绑定各自版本。

## 8. 接下来的推进顺序

1. 冻结本轮 V2 代码、基线与真实结果，将其作为已通过的开发基线，不再重复固定文本的同一 API 矩阵。
2. 先制定独立来源测试协议：冻结三方法、预算与评分，预定完成率/无违规完成率/放置比例/违规指标，使用没有参与调参的来源。先做无 API 的规划验证，再按新协议安排必要的真实模型验证。
3. 在开发数据上补充软预算及排序精度稳健性；与独立测试严格分开，不能看独立结果后调参再宣称同一测试集通过。
4. 若论文主张语言/VLM贡献，再设计新政策表达、实体绑定、真实条件分支及在线政策变化对照，保留强Parser及同一Executor。当前条件AST的相同双分支不满足这些目标。
5. buffer_size=3、图像感知与经验记忆分别作为后续扩展，先明确独立贡献与公平信息预算，不同时改动后只报告整体收益。

当前已无 V2 数值复现或真实调用工程阻碍；研究待办是独立验证和模型贡献证据，而不是再次复跑同一开发矩阵。
