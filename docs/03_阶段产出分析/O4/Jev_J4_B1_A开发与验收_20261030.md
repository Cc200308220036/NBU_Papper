### 查询与门控

`public_observation` 接收已有 `context.model_state` 的公共投影，不接收原完整 observation/task。参与查询的内容为箱体公开属性、布局/质量/尺寸、公共区域数值、容器和候选几何/支撑/载荷；对象句柄与候选 Cxx 不参与分词。`public_policy` 仅允许 `{"english_descriptions": [str]}`，不接收 AST、reference、来源、方法成绩或未来序列。状态中的原文、目标模板、缓冲到货索引不进入检索词元。

词元版本为 `english_ascii_numeric_6dp_v1`：小写 ASCII 英文词与数值，数值最多六位小数，长度 mm、质量 kg、角度 deg；无中文分词、停用词模型、词干化或 embedding。中文正文原样保留并按 UTF-8 计费；纯中文文本不能靠中文词元命中。查询词去重并排序，完整 `text/tokens/facts/units/tokenizer_version` 与 `query_digest` 落盘。缺失事实不填猜测值；明确的空布局高度为 0。

有限门控数值字段为 `placed_count/available_count/candidate_count/layout_height_mm/max_available_mass_kg/min_support_ratio/buffer_capacity/container_length_mm/container_width_mm/container_max_height_mm/container_max_payload_kg`；算子为 `eq/ne/lt/le/gt/ge`。集合字段 `available_categories/policy_terms` 仅允许 `contains`。未知字段、类型或算子拒绝。多个条件作 AND，有未知条件即记 `APPLICABILITY_UNKNOWN`，否则有不满足条件记 `NOT_APPLICABLE`。空条件表示没有自动门控；正文开放式限制仍须阅读，不代表自动证明全部适用。

R0 自动门控仅从历史容器公共尺寸/承载上限生成等值条件；M0 门控随卡内容摘要冻结。真实卡的证据支持及语义审核仍需后续阶段，不能用字段可执行代替语义支持审核。

### 原始历史

版本 `decision_event_self_contained_v1`，每个实际 PLACE 决策完整投影，不按装载成绩或违规筛选。保留所选箱属性、实际位姿/方向/载荷变化、几何支撑摘要、已放箱资源、公共区域、完整英文公共规则、反馈及新增反馈、终局件数与体积比例和停止原因。历史对象/规则别名只在本事件内有效，并核对定义；必要时补入规则或反馈引用的其他当前可见箱。

新增 `public_feedback` 由当时公开规则解析器和公开箱体顺序映射生成；新增实例由相邻已执行事件实际反馈的 identity 差集确定。原 B0 `feedback` 继续保留，没有为未执行候选追加结果。旧 B0 导出没有可解析的公共反馈映射时记 `PUBLIC_FEEDBACK_UNRESOLVED`，不能靠猜测补全；应从原封存训练实验重新导出。

省略字段固定列在 `history_preflight.omitted_fields`：未执行候选细节与分数、中文规则重复文本、目标模板、到货索引、不相关可选箱、几何分量/偏好特征、本地来源身份。所有已放箱资源保守保留，因此投影可能较大。缺少规则/箱体定义时排除；超过 1600 字节时整事件排除并保存来源、字节数、内容摘要和原因，不删负反馈或半条事实。

### 检索与冻结身份

R0/M0 使用同一实现与 tokenizer：`k1=1.2,b=0.75`，IDF 为 `log1p((N-df+0.5)/(df+0.5))`，查询词频为 binary；文档统计基于各模式完整冻结正文，在查询门控之前确定。只选正分，同分按正文摘要升序，完全相同正文再按文档 ID 升序。最多三条；正文单条最多 1600 UTF-8 字节；整个 `canonical(memories)`（含引号、转义、逗号和数组括号）最多 4800 字节，整条加入或跳过，再考虑后续条目。

结果保存完整查询、库/corpus/index/各模式 mode_index/config 摘要、所有门控实际值、正分排名、排除项、实际字符串数组、实际字节数、来源和 `retrieval_digest/injected_text_digest`。空结果为 `NO_MATCH`；超长、总预算、TopK 有各自排除原因。离线预检报告各模式条数、字节、来源覆盖、选中文档集中度与排除计数；没有服务 token usage 时为 null，不填 0 或把字节冒充 token。

新 `jev_memory_snapshot_v2` 内嵌完整规范化文档、词频、DF、正文长度及索引配置；`index_digest` 可验证，加载时从正文重算并比较，检索只用冻结索引评分；一致性核验从正文重算索引，不按当前查询更新索引。快照摘要、manifest 文件 SHA-256、corpus 导出摘要和引证/历史重算共同校验。包内无绝对路径，可迁移；加载和检索只读，MemoryStore 禁止写冻结目录。外部使用者须固定并传入可信 `expected_digest`；manifest 是内容校验清单，不是签名或外部信任根。

B0 `empty_snapshot()` 内容及配置中原摘要保持一致，旧证据包仍可加载；v1/v2 运行协议不接收新记忆。fixture 卡显式 `fixture_only=true`，fixture 证据自动传播到快照；正式远程加载拒绝 fixture。fixture 不放宽 active 卡已有的两来源、角色和审核门槛；仅 fixture 包允许本地虚构引证演示，生产冻结仍要求引证解析至训练导出事件。本批未实现 B2 的完整语义支持审核。

## 剩余限制与 B1-B 接入

B1-B 才把 `build_query` 和 `retrieve` 接入 episode/context 非空路径，绑定并持久化 snapshot/corpus/模式索引/query/retrieval/injected text，校验 D0/R0/M0 去除 memories 后请求一致、物理候选不变，覆盖响应已存/提交未评价/未知发送恢复。当前 `context.py` 仍拒绝非空库，`prepare-j4` 仍拒绝 R0/M0 批量执行。

当前真实材料只有一个来源组的两条旧 J3 训练轨迹，不能满足正式 J4 采集和 M0 两来源真实支持；保守完整投影使全部事件超预算。本批不扩展采集、不调大预算、不生成建议卡。正式 R0 前应在校准阶段审查投影/预算是否需要修订并重新冻结协议，不在测试结束后调整。fixture 仅证明接口行为，不能作为训练来源或经验收益证据。
