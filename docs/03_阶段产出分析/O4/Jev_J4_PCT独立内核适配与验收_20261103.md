## 接口与实际行为

公共接口、字段、状态语义和接入说明见 [stability/README](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/stability/README.md)。输入为 `PlacedState(container_mm, placed)` 和 `BoxInput(item_id, dimensions_mm, mass_kg, bottom_center_mm, yaw_deg)`；placed 必须保留真实提交顺序。`geometry.state_from_runtime`/`box_from_runtime` 提供显式桥梁，不排序、不读取未来物品，旋转后尺寸有一致性检查。

mm/kg、托盘底面中心原点、0/90 交换一次；用实际质量/旋转后体积求每箱密度，flag=False。每次创建独立 Space，容量 len(placed)+2，恢复每个前缀时真实调用 drop_box；核对 mass、COM、vertex_low/high、内核自动落高和原 z_base。超差 UNASSESSABLE，不调整候选。setting=2 在配置层和检测入口均封禁。

STABLE、UNSTABLE、UNASSESSABLE、ERROR 分开；基线失稳返回 UNASSESSABLE/BASELINE_UNSTABLE，基线数值故障为 ERROR，不归因于当前动作。未知失稳对象字段保持 null。结果绑定输入、配置、源码/依赖身份；数据/任务/决策/原 artifact 等运行绑定和篡改验证留目标二。

静态稳定性与包装 C/stackable/面积分载完全分开，不回写载荷、不双计已有上载。不修改候选、评分、排序、请求、原物理准入或执行流程。

## 实际验收与反例

37 项测试通过；12 个真实内核 fixture 保存完整输入、预期和结果。其中 1 个是**已知算法缺陷的 ERROR 验证**，不是稳定样本通过。异常保护注入测试单独标识，不冒充真实内核案例。初始 pytest 被宿主 ROS 自动插件缺少 lark 阻止；禁用无关插件后运行成功，没有安装训练或 ROS 依赖。保留 NumPy 2D cross 弃用警告，没有全局屏蔽。

关键祖先构造：底箱 60×200×100 mm、1 kg；上层平台 200×200×100 mm、1 kg，居中位于 z=100。新增 100×100×100 mm 箱位于 (60,0,200)。新箱自身 COM 在接触区内；10 kg 上载使平台组合 x 重心变为 54.545 mm，超过收缩后约 ±27 mm 支撑，真实内核 False → UNSTABLE。相同体积改为 0.1 kg，组合 x=5.455 mm，真实内核 True → STABLE。两者均真实恢复两箱并调用第三次 drop，没有旧判定替代。

对称双支撑跨接、直接中心落在三个支撑之一的三支撑、多层、地面、单支撑、非方托盘0/90转换均有有效数值/质量证据。重复及逆序评估除 duration 外结果完全一致，输入摘要不变。

**一般三支撑 LS 反例未解决：** 三个 40×40×100 mm、各 1 kg 支撑中心为 (-100,-80)、(100,-80)、(0,100)，桥箱 260×240×100 mm、3 kg，中心 (0,0,100)。上游真实返回 True，分流为 0.23896722212049054、0.2389672221204907、1.0388207288042486 kg，合计约 1.516755 kg，而桥箱为 3 kg。适配器返回 ERROR/FLOW_MASS_NOT_CONSERVED，不是 STABLE 或 UNSTABLE。输入/原始分流/差异保存在 `fixtures/three_ls_counterexample.json`。不经语义改变无法把该上游最小二乘变为守恒求解，本次不修算法；通用多支撑稳定判断仍未完成，后续必须单独版本化算法变更，不能通过归一化调成通过。

### 固定上游直接复算补证

后续独立复核绕过适配器，分别执行原下载模块（仅在进程内替换 np.float 兼容用法，不写原件、不执行上游初始化）和 vendor 模块，使用显式非负角点及真实密度。两者返回值、每条分流和系数矩阵完全一致，3 kg 负载均损失 1.4832448269547702 kg。由此排除适配器坐标/质量转换或保护层造成缺陷。

实际矩阵第一对支撑约束要求 f0+f1=0，与正载荷冲突；上游把总份额=1同样作为普通最小二乘软约束，因此残差导致总份额约0.505585。独立解析参考份额(5/18,5/18,4/9)满足质量与平面力矩平衡，仅用于证明构造可平衡，不进入运行内核。改符号、换约束求解或归一化都会改变固定算法语义，未实施。

补证命令为 `PYTHONPATH=semantic_pallet_planner/src python semantic_pallet_planner/tests/unit/pct_ls_reproducer.py --output semantic_pallet_planner/outputs/NEW_DIRECT_PCT_AUDIT`。实际独立补证包为 `outputs/VERIFY_JEV_PCT_DEFECT_AUDIT_20261103_01/`，含原始源码摘要、矩阵、残差、解析参考、命令和补充 handoff；保留首轮交付清单及其快照，不重签首轮产物。

### 恢复目标后的容量边界补验

首次恢复后补充超过上游默认 holder=60 的构造：61个互不相交地面箱按原顺序恢复，再评估第62箱；真实内核调用62次、结果62箱，总质量63 kg且地面质量63 kg，输入摘要不变。测试总计38项通过（原37项及新增容量检查），生产内核源码身份未变。补验输出为 `outputs/VERIFY_JEV_PCT_RESUME_AUDIT_20261103_01/`，旧37项交付及其摘要不重写。此项补强动态容量证据，不改变一般三支撑LS仍未完成的结论。
