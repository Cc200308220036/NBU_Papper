## 包装、字段与几何合同

source_preserving逐字段保留原始物理记录；不可支撑时保留来源的正承载值，同时派生有效顶部许可为0。controlled_packaging仅改变stackable与合成承载，完整原值另存original_physical。每个SKU＋包装配置固定映射，不对重复实例抽签；本批冲突数0，映射中共128个SKU＋包装配置对。

定标只用33种训练SKU质量的线性75%分位8.586 kg，向上取整得到9 kg的**合成实验尺度**。固定档位为不可支撑0、低承载9、普通27、加固54 kg；SKU哈希映射概率为0.10/0.25/0.45/0.20，种子20261102，无重抽或成绩筛选。基础层统一54 kg且允许支撑；紧张层只将异质层C乘0.5，其他物理/到货/支撑资格不变，4对逐字段检查通过。基础层与异质层属于不同场景，不作单因素难度结论。

这些概率、容量和包装含义没有工业抗压试验依据，不能由自重推断为真实抗压能力。无实测包装额定值是未解决缺口；本轮仅验证实验合同与静态正确性，不为改善成绩调整参数。

`max_top_load_kg`是唯一主容量C，`top_load_limit_kg_synthetic`为等值兼容别名；`effective_top_permission_kg=C if stackable else 0`。没有独立随机业务阈值或禁压标签。保留原尺寸、mass_kg、完整到货与来源身份；类别仅作背景，regions/rules为空。SKU与来源身份仅供本地审计，目标二须实现请求匿名化。

geometry_contract.json声明mm/kg、单箱质量均匀、几何中心重心、底面中心坐标、x沿长/y沿宽/z向上、0°/90°水平朝向，旋转后尺寸只交换一次。以旋转后尺寸进行中心/角点往返及mm/m换算。局部接触中心、支撑图、分载比例、累计载荷、组合重心与稳定性结果不预填固定属性，封闭Schema拒绝这些字段。

候选器精确高度接触/边界/碰撞、1e-9 kg载荷容差，与独立oracle的1e-6 mm/kg容差分别记录，未统一或调宽。70%面积阈值、接触矩形内局部中心检查及面积分载是近似，不是完整力矩平衡或动态抗坍塌证明。源码仅使用0/90轴对齐尺寸，不能据此确定有符号yaw旋转的手性；未来第三方适配前须核实，现记UNVERIFIED。

## 构建、加载与实际验证

  --repo "$PWD" \
  --output "$PWD/semantic_pallet_planner/outputs/DATA_JEV_PACKAGING_LOAD_NEW_ID"
python -m semantic_pallet_planner.jev_select validate-packaging-dataset \
  --dataset semantic_pallet_planner/outputs/DATA_JEV_PACKAGING_LOAD_20261102_02

## 目标二交接与停止边界

handoff.json包含数据/配置/源码/来源摘要、字段映射、已通过检查、缺口、NOT_RUN及禁止改动的历史产物目录；verification/protected_inventory.json提供具体不可重写文件。stability_readiness.json列出现有检查、接触/容差/凸包判定潜在冲突、祖先载荷与分载口径；没有编造第三方API。

未解决：工业包装依据缺失、四来源均已暴露训练、没有可行布局见证、符号yaw手性未证实、目标二请求/运行/评价/记忆拒绝门与联合身份尚未迁移。新任务不得直接送入旧v1/v2运行链路并沿用旧成绩；旧语义经验不得仅改摘要后重用。R0自包含事件和M0真实非空注入需另验收，数据完成不意味着记忆闭环完成。

本轮没有读取API密钥、调用Jev/DeepSeek、下载/训练/接入PCT、替换物理判定器、订单效果矩阵、分支搜索或全量回放。新物理版本若启用，必须重新认证见证。目标一到数据独立加载、静态检查与交接完成为止。
