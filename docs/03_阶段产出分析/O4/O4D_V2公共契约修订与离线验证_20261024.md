## 已完成改进

| 内容 | V2行为 |
|---|---|
| 类别枚举 | 显式公开`food`食品、`glassware`玻璃制品、`electronics`电子产品/小家电、`household_cleaner`清洁用品、`general`普通货物；中文仅为含义，不是可输出别名 |
| 重量与类型 | 显式公开`light/medium/heavy`；布尔字段仅接受boolean；kg字段接受有限非负数，拒绝boolean和数字字符串 |
| 输出Schema | 根据字段约束value；仅数字字段允许`lt/le/gt/ge`；Schema与运行校验均限制选择器深度≤4 |
| 字段诊断 | 提供JSON Pointer路径、原因、允许枚举或类型；未知对象仅列当前公共对象ID；覆盖引用错误提供公开规则要求 |
| 绑定诊断 | 逐字段核验request_id、state_hash、observation_digest、instruction_digest，以及缓冲hash/event_index；错误时列当前公共期望值，不改写响应 |
| 一次修复 | repair_error为结构化对象，包含契约版本、错误码、issues、最多32768字符的上一次响应文本；最多再请求一次，计入预算 |
| 账目与回放 | 每次尝试保存repair_diagnostic；回放从原始响应重算诊断与下一请求摘要，拒绝诊断被篡改后重新签名的产物 |

修复输入只来自公开校验约束、当前公共绑定和模型自身输出。合法但错业务的AST原样进入独立评价，不触发答案修复。不做类别别名替换，不由Parser或Oracle兜底，不放宽物理检查。

`prepare`在计划中保存契约/提示版本，并导出`protocol/response_single.schema.json`和`response_buffer.schema.json`；源码和Schema均在运行前冻结。

## 可复现命令

从仓库根目录执行，使用新的目录名，不能覆盖本轮或旧实验。下列命令均为离线，不发起真实模型请求。

```bash
export PYTHONPATH="$PWD/semantic_pallet_planner/src"
export PYTHONDONTWRITEBYTECODE=1

python -m semantic_pallet_planner.runners.o4_remote_v2 --help

python -m semantic_pallet_planner.runners.o4_remote_v2 prepare \
  --profile compile-smoke \
  --output semantic_pallet_planner/outputs/PLAN_O4_D_V2_OFFLINE_REPRO_NEW

python -m semantic_pallet_planner.runners.o4_remote_v2 run \
  --plan semantic_pallet_planner/outputs/PLAN_O4_D_V2_OFFLINE_REPRO_NEW \
  --output semantic_pallet_planner/outputs/EXP_O4_D_V2_OFFLINE_REPRO_NEW \
  --api-budget 48 --offline

python -m semantic_pallet_planner.runners.o4_remote_v2 replay \
  --output semantic_pallet_planner/outputs/EXP_O4_D_V2_CONTRACT_OFFLINE_20261024_01
```

后续源码改变时，回放使用该实验`frozen_plan/code_snapshot/semantic_pallet_planner/src`设置PYTHONPATH，并保留`PYTHONDONTWRITEBYTECODE=1`。不修改旧清单以适配当前源码。
