# O4-D独立能力实验框架与开发交付

日期：2026-10-24。实现版本：`o4_d_research_v1`。本轮完成实验开发、来源审计、预留数据和计划、离线工程验证，真实API调用为0。模型结果留给用户在环境终端执行。

## 实际交付

新代码位于`o4/research/`，入口为`runners/o4_research.py`。原A/B/C/F/A5、远程V1和V2实现保留。业务AST、公共观测、实际图像传输和一次修复复用已经版本化的协议。

| 模块 | 职责 |
|---|---|
| `data.py` | 审计既有来源，排除记录来源与重复几何/质量窗口，派生新订单、属性、固定题和在线任务，封存公共/私有数据 |
| `specifications.py` | 独立声明六类政策及受控/自然语句，不运行Parser获取真值 |
| `parser.py` | 公开冻结的词法归一化及自然子句解析强基线，不按case_id或私有答案检索 |
| `validation.py` | 新组合16个独立算术/接触期望的正反例，运行与参考解释分别核验 |
| `metrics.py` | 规则签名、84个载荷/接触有限见证、对象集合、允许集合与来源配对统计 |
| `episode.py` | 五编译来源接入冻结单箱/缓冲规划；Parser不支持保存失败并终止该episode，不中断整批 |
| `experiment.py` | 固定/在线×开发/校准/留出计划、重复与预算、逐job输出、事件审计及无网络回放 |
| `overlay.py` | 将外部编写的新表达导入新的封存数据，保留参考规则并同步在线任务，不伪造人工签认 |
| `testing.py` | 只读取序列化公共输入的标记服务替身，不参与真实远程运行 |

配置为`configs/o4_d_research_v1.json`。主要接口包括`build`、`verify`、`prepare`、`run --offline/--remote`、`replay`和`import-expressions`。

## 数据与隔离

正式预留数据目录：`semantic_pallet_planner/outputs/DATA_O4_D_RESEARCH_20261024_01`。

从本地10003个BED-BPP订单中，按固定种子、来源ID、首12箱、机械字段合法性及几何/质量窗口去重选择40个来源，排除V1数据和既往实验已记录的来源标识。不按模型表现、政策可行性、Parser表现或完整码垛是否成功筛选，不通过重抽样隐藏失败。

- 开发8来源、校准8来源、留出24来源，来源及所选几何/质量窗口互不重复。
- 总528条固定题：开发96、校准96、留出336。
- 总160个在线任务：开发32、校准32、留出96；每来源两政策×规范/自然表达。
- 控制轨保留规范表达；surface轨检验语法表面变化；expression轨检验自然子句表达；留出集另有两种组合政策轨。
- 同源同政策的表达配对保持物理状态、候选及参考规则相同；完整订单各方法独立推进真实状态。
- 来源、划分、参考AST、候选与见证保存在private/audit中，编译请求只有当前公共事实与业务文本，不输入候选答案或未来箱。

物理承载100 kg、可堆叠性、类别、加固与标签均按公开固定方法模拟派生；BED-BPP提供尺寸、质量、到货序列。不能把派生属性称为工业测量。来源排除指仓库记录可核验范围，不保证基础模型预训练未见。

## 公平对照与测量

五来源：原Public Parser、归一化Parser、V2 Text、同模型同事实Image、Oracle AST。Oracle为特权参考，不是全局最优规划。

固定题保存有效AST、规范化规则语义、对象集合、条件/覆盖、有限见证、候选允许集合及误放/误拒。非法输出和不支持表达都保留在全部计划分母中。不同结构的表达不直接按JSON不相同判错；整数/小数的等值数字在新研究签名中统一，旧评价器不改。

在线主比较固定`single_greedy`，改变编译来源；可另行冻结FIFO、启发式、搜索计划。搜索不调用模型，已提交物理动作由独立评价检查，错误AST造成的业务错误原样保留。

测试重复默认3次，开发/校准各1次；每次远程编译独立发出HTTP请求，不使用旧响应缓存。统计先按题及重复配对，再按来源平均和聚类bootstrap；同时列模板族结果。主指标固定题为规则语义一致，在线为无违规整单完成；实用差异阈值0.05，在线件数比例非劣效边界0.05。这些是本轮预声明设计参数，不是通用标准或已经确证的业务门槛。

区间条件于本轮模板库，多个对照仅探索性报告；24来源、3次重复没有宣称经过功效认证。`confirmatory_claim=false`、`power_certified=false`在结果中明确保存。语义签名、有限行为见证和允许集合分别报告，不把84个有限见证当无限逻辑等价证明。

## 调用前发现的证据边界

不使用模型的强基线审计显示：原Parser只覆盖规范表达，归一化Parser在自带528题上均与独立参考语义一致。说明当前程序语料对强基线没有正向准确率增量空间，不能把模型胜过原Parser的句式拒绝解释为超过强规则系统。

因此，自带程序语料首先用于工程可靠性和受控来源/组合测试；不要为了寻找优势直接扩大其API数量。外部自然语言可通过`import-expressions`封存为新语料版本，再检查强基线差距并执行真实对照，保持难题、控制题和失败分母。导入只认证结构与隔离，不认证作者身份或新文本与旧参考的语义等价。

本轮程序模板由开发者可见，归一化词典/语法公开，不属于外部独立人类盲测。留出组合是相对于本轮开发/校准数据，不能声称某个基本选择器从未在历史代码出现。
