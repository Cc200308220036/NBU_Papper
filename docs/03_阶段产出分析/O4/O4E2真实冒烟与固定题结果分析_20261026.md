## 2. 唯一一次修复的具体原因

发生于冒烟E2_G24、remote_text，编译ID为`E2C000023`：

1. 首次请求为账目attempt 23，返回`instruction_digest`长度63，正确摘要长度64，漏抄一个字符。
2. 程序返回`invalid_binding`，诊断精确指向`$.instruction_digest`，没有接受过期/错误绑定，也没有替换返回摘要使其通过。
3. 账目attempt 24进行一次模型重试，模型返回正确摘要，校验通过。
4. 比较两次原始回答，唯一变化字段是`instruction_digest`，`policy_ast`完全相同。

因此这不是相对位置理解错误，也不是用参考AST修正业务答案；本次真实实验验证了“拒绝错误绑定—定位诊断—最多一次修复”的路径。原始失败和修复响应均保留。

## 3. 独立核验内容

核验冒烟78项、固定题150项封存文件，以及两份各202项的冻结计划；检查计划/实验输入及模型配置一致、执行源码与计划快照一致。

对每个远程任务核对源请求、Text/Image条件、状态/指令/观测绑定、准确公共事实、实际PNG几何/文字/字节、原始HTTP响应与解析payload、保存响应与账目对应。使用保存的公共输入、提示、模型参数和前一轮诊断重建每一次请求体，摘要与账目一致；未发送HTTP请求。两种条件使用相同deepseek-flash、temperature=0、thinking disabled及相同事实，Image额外附真实PNG。

重新解析原始回答并计算语义及允许集合，确认保存评分不是仅靠验收摘要推断。模型原始AST与参考AST多数不同：冒烟Text/Image各0/12原始结构完全相同，固定题各1/24完全相同；业务语义全部相同。规则ID、排序及白名单等价表示不应直接计为业务错误，原始回答未改写。

## 4. 支持的结论与限制

支持：真实模型能够在本轮构造的E2开发题上正确编译方向、主客体、间距，以及指定组合规则；当前协议、PNG输入链路与一次绑定修复能实际运行。结合已通过的E2离线四规划器实验，可以记录“E2工程离线完成、E2真实编译验证完成”。

仍不能声称：

- 模型优于强Parser：各来源均满分，没有本轮准确率优势。
- 图像提供业务增量：Text与Image最终语义及允许集合相同，本轮未观察到准确率增量。
- 真实模型在线订单完成：`real_online_status=NOT_RUN`；固定观测编译不是模型连续决策，不能用Parser/Oracle离线闭环替代。
- 跨订单或未见表达/组合泛化：`unseen_generalization=NOT_MEASURED`。固定题是12组配对的24状态，不是24个独立订单；全部固定题每题2个观测对象、2个指定候选，冒烟每题1个候选。
- 已验证连续空间覆盖或机器人执行：本轮复核指定候选判断，不新增候选覆盖或机械执行证据。
