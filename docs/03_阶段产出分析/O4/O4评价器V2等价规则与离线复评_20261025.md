# O4评价器V2等价规则处理与离线复评

日期：2026-10-25。版本：`o4_equivalence_evaluator_v2`。本轮只新增评价模块、离线复评入口、测试和分析产物。真实API调用0；没有修改旧评价器、客户端、提示、Schema、规划器或原始实验。

## 1. 处理的等价范围

在目标、优先级与覆盖关系保持一致时，将`no_top_load`与`max_top_load(constant_kg=0)`归为同一顶部限载规则。比较发生在新建的签名中，既不修改模型回答，也不把归一化结果送回模型或执行器。

同时保留已有的规则ID重命名、规则重排、and/or子式重排及重复项消除、object_ids排序、接触左右交换等不变性；数值使用精确十进制值比较，允许3和3.0一致，不按容差把非零值并入0，也不先转float损失大整数精度。

以下仍不等价：限载0和1、0和1e-12、字段标签限值和常数0、不同作用对象、遗漏规则、遗漏或改变覆盖引用、不同优先级。优先级在新声明签名中保留；即使某次无覆盖规则的优先级变化未影响动作，也不会因此归一化为一致。

这是预声明的有限等价处理，不是任意逻辑公式等价求解器。不因为当前候选集合一致就认定完整政策正确。

## 2. 独立模块与指标

实现：[evaluation_v2.py](../../../semantic_pallet_planner/src/semantic_pallet_planner/o4/evaluation_v2.py)。只依赖公共序列化/Schema和既有独立参考解释器，不导入待测编译器、运行规范化器、Executor、Planner或客户端。方法与参考的候选判定都由独立解释器重算。

| 指标 | 比较内容 |
|---|---|
| raw_ast_equal | 原始AST结构一致，和等价分数分开 |
| semantic_equal | 声明的等价归一后，完整规则、优先级和覆盖图一致 |
| rule_count_equal | 是否遗漏/新增规则，不合并重复规则来掩盖缺失 |
| selector_structure_equal | 目标条件/接触两侧的选择器结构与规则族一致 |
| applicable_objects_equal | 每条规则在已观测对象中的实际匹配集合；不混入载荷限值、优先级或覆盖 |
| limits_equal | 对应限载规则的常数或标签字段是否一致 |
| priority_equal | 对应规则优先级数值是否一致 |
| overrides_equal | 经过规则对应后的显式覆盖边是否一致 |
| conditions_exceptions_equal | 选择器及覆盖关系是否一致；不直接复用完整语义分数 |
| allowed_set_equal | 同一给定状态和候选下的允许集合是否一致 |

限值、优先级和覆盖关系按“规则族＋归一后的选择器”建立对应，不按模型rule_id猜测。范围不匹配或同一范围有多条规则、无法唯一对应时，相应组件为null，明确记录`SCOPE_MISMATCH`或`AMBIGUOUS`。没有限载规则时limits_equal也为null，而非凭空记为正确。

汇总同时给出correct、comparable、not_comparable、planned_denominator；整体语义和有效率始终保留全部计划分母，不能删去失败或null后宣称全样本正确。对象集合仅代表当前已观测对象，选择器结构另报，防止错误筛选条件碰巧选中相同对象。

例如“所有箱体限载2 kg”变成“所有箱体限载3 kg”，对象和条件可正确，限值和整体规则错误；反之，不同筛选条件即使当前都只选中同一个箱子，也不能算整体政策正确。
