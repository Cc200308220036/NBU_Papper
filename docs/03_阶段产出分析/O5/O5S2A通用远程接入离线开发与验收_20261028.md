# O5 S2-A 通用远程接入离线开发与验收

日期：2026-10-28。阶段范围：S2-A通用工程，不是S2-B真实provider验收，也不是S2-C真实八单pilot通过。

## 1. 实现内容

在保留原A默认、E2/共享评分/物理oracle/vendor和历史原件的条件下，新增远程profile、通用HTTP适配、完整图文输入预算、十进制费用预留、共享campaign账本、运行时接口、计划/源码/依赖冻结、显式授权预检和pilot入口，以及零网络verify/report。

原 `o5/episode.py` 只增加可选runtime参数，继续共用逐箱到货、独立物理检查与提交、完整分母及checkpoint/journal逻辑。默认S1行为和原离线入口不变。新增模块使旧冻结计划与当前源码不一致，按原规则拒绝继续；旧快照、数据和报告不改写。

关键实现：

- 系统提示、公共JSON、修复错误码与两张图共同计入输入上界；超过12000在发送前拒绝，输出≤256，图像哈希绑定实际发送字节。
- 原始请求一次，只有格式/绑定错误允许一次修复；SDK/HTTP层不重试，拒绝/截断/服务错误不转成“正确动作”。
- 先在全局锁内预留金额，再发送；未知结果保留费用上界、停止campaign、不重发。预检和pilot共用同一账本和合计金额上限。
- 原始receipt先落盘、再结算/解析；恢复可复用原件。缺账本、篡改响应/body/图片/源码或删除未知暂停标记均拒绝。401/403/404/429、重定向、模型漂移、usage超上界及连续两次5xx停止批次。
- 实际授权记录与计划、profile、账户、币种/金额、campaign绑定，非敏感原件随run保存，恢复和只读复核重新校验。
- verify不构造远程client，重建完整结果和中断任务已提交prefix；报告区分HTTP替身与真实运行，不以模拟usage冒充账单。
