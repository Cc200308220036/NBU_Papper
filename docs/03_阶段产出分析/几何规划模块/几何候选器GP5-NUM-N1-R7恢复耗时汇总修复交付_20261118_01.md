现有 timings 行只允许 segment 字符串和非负数字 seconds，采用以下输出约定，绝不以 0 代表未知：

| 输入情况 | 汇总输出 | 含义 |
|---|---|---|
| 所有适用事件该字段均为数字 | 原 segment 名，seconds 为原顺序求和 | 该段样本完整已测；不是整单完整墙钟的额外证明 |
| 同字段部分数字、部分 null 或缺失 | `measured_partial/<原字段名>`，仅加已测数字 | 已测部分和，原段完整总时长 UNKNOWN，不输出原裸段名 |
| 该字段全部 null/未测，或无样本 | 不输出数字行 | UNKNOWN/无可用测量，绝不能按缺行为 0 |
| 确实测得 0 或 0.0 | 保留为数值零 | 有测量，与未知不同；零混 null 时仍是部分和 |

适用事件为含 decision_id 或非空 timings 的事件；无决策耗时的到货事件不算时间样本。同一适用集合内缺字段保守地视为未测。每类 monitor 的 result.duration_s 同样处理：缺 result/缺 duration/null 不伪造零；没有 monitor 时不再产生虚假的零耗时行。非数字且非 null 的样本仍拒绝；合法原 null 事件和原零值不回写。

消费者只能把裸段名视为该段完整样本和；`measured_partial/` 前缀不参与完整耗时排名；缺行表示不可得。输出不能区分“从未适用”与“全部未测”的细分类别，该区别需查原事件，本轮不新增指标字段。未修改外层追加的 invocation_wall_s；它是本次调用实测时间，不能替代跨中断完整订单墙钟。
