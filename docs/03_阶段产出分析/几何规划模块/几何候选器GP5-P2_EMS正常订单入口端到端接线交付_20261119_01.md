## 2. 新的正常启动入口与显式 E2 写法

### 2.1 正常订单启动入口（默认 EMS）

- 计划构造：[prepare_operational_order_plan](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/packaging_geometry_protocol.py#L86-L108)
  `prepare_operational_order_plan(adapted, data_identity=..., scope=..., native=True)`
  省略 `backend` 时，在构造与冻结前选定 `DEFAULT_GEOMETRY_BACKEND`（`ems_surface_hybrid_v1`），写入 `plan['jobs'][i]['backend']`。
- 配置加载与身份绑定：[load_order_config](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/geometry_order_execution.py#L44-L62)
  从 `plan['jobs']` 读取最终 `backend`（`ems_surface_hybrid_v1`），写入 `config['candidate_backend']`、`config['generator_config_digest']` 与 `config['runtime_identity']['strategy_identity']`。
- 公共订单执行：[run_order_job](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/geometry_order_execution.py#L139-L198) -> `episode.run_episode` -> `episode.decision_inputs` -> `CandidateProvider.build`。

### 2.2 显式 E2 写法

- 计划构造：`prepare_operational_order_plan(adapted, data_identity=..., scope=..., backend='e2_original_v1', native=True)`，将 `e2_original_v1` 写入计划与运行配置，公共订单循环实际调用 `o4.extensions.e2.candidates.generate`。
