UNSTABLE 按 PREDICTED_STATIC_INSTABILITY 停止，失败箱不放、不出缓冲、不增加已装件体积质量；UNASSESSABLE、ERROR 分别不可评价/技术失败停单。禁用不能冒充稳定，生成/存储/身份错误不记成无解或预测失稳。正常路径必须合法完整指标及 EOS/终止原因一致。

恢复必须来自未来同身份同次运行产生的相位一致 checkpoint/blob/accounting 副本，不回滚活动根，不移植后相位账本。SELECTED 新监测/提交 1/1；MONITORED 0/1、原监测复用1；COMMITTED 0/0并正常返回合法指标。三相位生成/发布/选择增量均0，保留原 selection、proposed_action 和 MONITORED result_digest。累计/增量独立核对。用事件推导耗时期望；数字/null 混合时只输出 measured_partial/<segment> 已测部分和，缺失不是0，不输出裸名完整用时。后续工具可复用已归档 timing_assertions，但不能用其纯测试替代真实恢复收据。

四个主项都应 STABLE、ALL_ITEMS_PLACED，精确动作及提交数满足 required_coverage；六项恢复与真实账本满足 validate_completion。技术失败、取消和 NOT_RUN 保留完整分母，不作排名。K03 adapter-only 和公共真实负向端到端均单列 NOT_RUN_OUTSIDE_PROPOSAL；ancestor_heavy 不满足公共70%前缀，不能冒充公共可达负例。四个正向完成不自动关闭这些 A03 边界。

## 后续预算提案

当前合同的硬天花板为 assessment≤12、solver/LP≤512；本提案收紧为 **8/128**，仅供未来独立冻结/授权审阅，不是本轮许可。

- 新鲜运行：K01 两后端各1评估，K02 两后端各2评估，共6入口、6次提交。
- 恢复：仅两个 K01 SELECTED 各补1入口，共2入口；六次恢复共补4次提交、复用2次监测。MONITORED/COMMITTED 不增加入口，全部不重新生成/发布/选择。
- 正常稳定路径静态 LP 估算：单地面箱4接触顶点，physical_feasibility + max_network_interior + 4 lex_force = 6次。两箱上层网络8顶点为10次，exact_adapter 在非空前缀还先评估地面 baseline 6次，所以上层单次 assessment 预期16次。新鲜两后端各(6+6+16)=56，恢复2×6=12，合计68次。128提供有界余量，不授权额外 case/入口/种子；该估计来自源码静态路径，未经数值运行证实。

发生不稳定、不可评价或数值错误时可能提前停止或走证书路径，不能保证实际等于68。真实 assessment 与每一次 balance_network.linprog 独立在调用前预留并 fsync；单入口内部触顶也须停，不预留结果成功再计数、不把 kernel_calls 或网络求解次数充作 LP 次数。STARTED 残留按 geometry_meter_unknown_call 停止，ERROR 保留；无隐式重试、补额度或加样本。K03及真实负向未纳入本提案，旧 E21/21 和前轮替身7/7均只作历史，不能并入新真实额度。
