# O3布局保留机制消融运行说明

2026-10-19。本入口对应新的离线布局消融runner，不改变旧O3运行器、执行器或原实验。实验设置见[冻结协议](../02_阶段实施方案/O3/O3布局保留机制与消融协议_20261019.md)。

## 范围与输入

仍为真值当前状态、`buffer_size=1`、原物理候选器、Top-K=16；Public Parser解析相同公开指令，分别以原排序、同分布局排序或显式软预算下的布局排序选址。没有Flash或其他远程模型调用，不能将结果称为VLM增量。

`relaxed_*`使用协议规定的新软预算：相对同状态的原Executor锚点，低位质量最多损失0.05，居中质量最多损失0.25。这是实验配置中的软政策变体，不代表原自然语言优先级被严格保持，也不放宽物理或业务硬约束。原公开政策摘要仍标识基础文本；变体、预算、评分及代码版本另在manifest和逐步trace中绑定。

## 运行

从项目根目录执行。输出目录必须不存在：

```bash
MPLCONFIGDIR=/tmp/layout-mpl PYTHONPATH=semantic_pallet_planner/src \
python -m semantic_pallet_planner.runners.layout_ablation \
  --output semantic_pallet_planner/outputs/MY_LAYOUT_TRAIN_NEW \
  --split train --limit-orders 1 \
  --variants original strict_layout relaxed_geometry relaxed_full
```

以上为1来源订单×2政策×4变体×2模式＝16个episode的接口试跑；train订单明确来自已见开发来源。全部9变体的10来源validation矩阵为360个episode：

```bash
MPLCONFIGDIR=/tmp/layout-mpl PYTHONPATH=semantic_pallet_planner/src \
python -m semantic_pallet_planner.runners.layout_ablation \
  --output semantic_pallet_planner/outputs/MY_LAYOUT_VALIDATION_NEW \
  --split validation --limit-orders 10
```

运行后自动全量回放、复算逐单指标，并比较`original`与既有安全/观察模式Public Parser的逐步状态和动作。所有源码/场景、协议和配置保存摘要；运行前后核验两个原实验目录的完整文件清单。当前版本不支持resume；中断时保留目录，审查后换新目录重跑，不手工补造成功记录。

## 阅读产物

1. `acceptance_report.json`：计划矩阵完整、回放、物理检查、版本及原始文件保护。
2. `results.md`、`metrics/summary.json`：安全与观察模式分开，各变体的完成、完整无违规、件数/体积放置比例和违规实例。
3. `metrics/per_episode.csv`：逐订单政策配对，失败任务也在分母。
4. `metrics/paired_cluster_comparisons.json`：先按来源订单平均双政策，再聚类bootstrap；仅探索性区间，未作多重校正。
5. `episodes/<mode>/<variant>/<episode_id>/steps.jsonl`：实际公开请求、候选摘要、原策略锚点、允许集合、布局特征、软目标损失、提议与提交、状态及业务评价。
6. `replay_report.json`：重新生成候选、重新选址、独立物理/业务检查、逐步状态与完整逐单指标复算，并核对历史原策略。

若矩阵通过后需要额外图表：

```bash
MPLCONFIGDIR=/tmp/layout-mpl PYTHONPATH=semantic_pallet_planner/src \
python semantic_pallet_planner/scripts/report_layout_ablation.py \
  --root semantic_pallet_planner/outputs/MY_LAYOUT_VALIDATION_NEW
```

该脚本只读取已保存轨迹，新增逐来源表、动作变化表、预算检查和图像；不重新选择、不调用模型。两组3D案例预先固定为0052/P0和0054/P1，不能把展示案例当全体胜率。

## 关键比较与结论边界

- `strict_layout−original`：只改变原最优等价集合内的同分排序。
- `relaxed_geometry−original`：包含显式软政策取舍，不是纯布局特征收益。
- `relaxed_full−relaxed_geometry`：相同预算下，四项布局代理相对原几何评分的增量。
- `relaxed_wo_*−relaxed_full`：组件的开发期消融；若删除项更好，保留负结果，不反向声称完整模型最优。

矩阵仍来自已被反复查看的10个validation来源订单，所有改进都属于开发证据。预算、参考矩形和评分是启发式设定；后续需要独立来源及参数稳健性验证。工程PASS不要求新策略胜出。
