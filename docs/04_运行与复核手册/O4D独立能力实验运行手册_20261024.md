# O4-D独立能力实验运行手册

本轮只开发与离线验证。以下真实API命令由用户在终端执行；没有由Agent运行。所有目录拒绝覆盖，预算包含失败和至多一次修复，回放不增加真实样本数。

## 环境与版本

```bash
conda activate pallet_vlm
cd /home/cyw/NBU_Papper
export PYTHONPATH="$PWD/semantic_pallet_planner/src"
export PYTHONDONTWRITEBYTECODE=1
read -rsp 'DeepSeek API key: ' DEEPSEEK_API_KEY
export DEEPSEEK_API_KEY
```

研究入口为`python -m semantic_pallet_planner.runners.o4_research`；原12题/144题开发基线仍使用`runners.o4_remote_v2`。两入口不可交换计划。

五来源为`public_parser`、`normalized_parser`、`remote_text`、`remote_image`、`oracle_ast`。Public Parser、归一化Parser及Oracle不产生远程请求；Text和Image使用同一模型及参数，同样的准确事实和箱面事实，仅Image附实际PNG。

**本轮调用前审计发现：自带528题上归一化Parser为528/528语义正确。** 所以默认程序语料可检验协议可靠性、规则覆盖及来源迁移，无法提供超过强Parser的正向准确率增量空间。先执行V2基线或小规模校准；下面的大规模TEST命令属于可选能力/可靠性测量，不建议为了寻找模型优势直接全部运行。检验更广语言适应时，使用文末的外部表达导入流程；仍保留冻结强基线，不人为削弱它。[审计证据](../../report/analysis/O4_D_RESEARCH_20261024_01/baseline_headroom.json)的仓库实际路径为`report/analysis/O4_D_RESEARCH_20261024_01/baseline_headroom.json`。

## 研究数据与预冻结矩阵

默认数据：`semantic_pallet_planner/outputs/DATA_O4_D_RESEARCH_20261024_01`。

| 计划名中间段 | 来源 | 独立题/订单任务 | 重复 | 五来源记录/episode | API尝试上限 |
|---|---:|---:|---:|---:|---:|
| FIXED_DEVELOPMENT | 8 | 96题 | 1 | 480 | 384 |
| FIXED_CALIBRATION | 8 | 96题 | 1 | 480 | 384 |

## 开发、校准与留出实验

先运行开发或校准固定题，分析接口与测量是否正常。不要根据留出模型结果挑题、删除失败、修改Parser或提示后继续当同一测试。

```bash
# 开发固定题，可用于诊断；本次执行的是远程请求。
python -m semantic_pallet_planner.runners.o4_research run \
```

## 结果检查与只读回放

把`--output`换成需要复核的实际目录：

```bash
python -m semantic_pallet_planner.runners.o4_research replay \
  --output semantic_pallet_planner/outputs/EXP_O4_D_RESEARCH_FIXED_CALIBRATION_REAL_20261024_01
```

- `acceptance_report.json`：完整性、替身标记、实际尝试、Parser不支持数、D4；PASS仅指工程记录完整，绝非模型满分。
- `metrics/study_summary.json`：按轨道/方法分母、首要指标、来源配对探索性区间、表达配对及进度保护指标。
- `metrics/summary.json`：首答/修复、tokens、缺失usage、耗时、API失败。
- `metrics/rows.json`、`jobs/`：逐题/逐订单完整结果；`unsupported_construct`保留为失败。
- `responses/`及`audit/attempts.json`：真实请求响应、原始文本、结构化修复和调用账目。
- `episodes/`、`audit/events.json`：逐事件守恒、真实物理提交及独立业务评价。

语义签名、有限见证和允许集合分别报告。有限见证通过不能证明任意逻辑等价，未显著优于Parser也不能推断等效。

## 离线复现与新计划

已有计划可将`--remote`替换为`--offline`，并采用新的输出目录，不需要密钥。此时所有模型结果均标记服务替身，不可当真实准确率。

若需要冻结另一个规划器，例如缓冲搜索：

```bash
python -m semantic_pallet_planner.runners.o4_research prepare \
  --corpus semantic_pallet_planner/outputs/DATA_O4_D_RESEARCH_20261024_01 \
  --mode online --split calibration --planner buffer_search \
  --output semantic_pallet_planner/outputs/PLAN_O4_D_RESEARCH_BUFFER_CAL_NEW
```

预算使用该计划输出的`maximum_api_attempts`。新的配置和代码需在真实调用之前冻结；不要直接编辑封存计划。

## 主张边界

来源“留出”仅指不在本仓库可核验的既往来源记录中，不证明基础模型预训练未见过原始BED-BPP。图像/业务/物理属性均为准确仿真设定，非工业实测。

表达采用程序构造的受控句式、自然语句和模板族留出；归一化Parser词典及语法公开，可能覆盖这些表达。模板由本轮开发者可见，不是外部独立人类盲测。组合仅在本轮开发/校准数据中留出，不声称其原语从未出现在历史代码。

区间按订单来源聚类，条件于本轮固定模板库；同时列模板族结果，不把模板相同的多订单当独立语言样本。24来源规模未做功效保证，多项比较仅探索性报告，不输出确认性“模型优势已成立”。后续若需要外部自然语言或正式功效结论，需另行冻结独立语料及统计设计。

## 外部表达导入

导入在新的数据目录进行，不修改当前程序语料、不修改参考AST、不增加独立订单数量。外部编写者可以对已有业务含义提供新的明确表达；语义是否保持需要独立核验，导入程序不认证人为签名或标注正确性。

输入JSON格式如下，`rows`必须恰好覆盖选定split中每一条`track=expression`的固定题；实际case_id从该数据的`private/input_snapshot.json`读取，不能只提交下面一行示例。不同来源的同语义题可共享表达模板族，但模板族不得与其他split重名，文本不得与其他split完全相同。

```json
{
  "schema_version": "o4_research_expression_overlay_v1",
  "provenance": "填写实际编写来源与方法，不虚构审阅人",
  "split": "test",
  "rows": [
    {"case_id": "实际Q编号", "text": "保持原业务含义的新完整表述", "template_family": "external_family_01"}
  ]
}
```

```bash
python -m semantic_pallet_planner.runners.o4_research import-expressions \
  --corpus semantic_pallet_planner/outputs/DATA_O4_D_RESEARCH_20261024_01 \
  --overlay /绝对路径/expressions.json \
  --output semantic_pallet_planner/outputs/DATA_O4_D_EXTERNAL_EXPRESSIONS_NEW

python -m semantic_pallet_planner.runners.o4_research prepare \
  --corpus semantic_pallet_planner/outputs/DATA_O4_D_EXTERNAL_EXPRESSIONS_NEW \
  --mode fixed --split test \
  --output semantic_pallet_planner/outputs/PLAN_O4_D_EXTERNAL_EXPRESSIONS_NEW
```

相应在线任务会同步使用这些表达，保持同源同规则的固定/在线对应关系。导入状态为`PROVIDED_NOT_INDEPENDENTLY_VERIFIED`，不自动升级为人工审阅通过。原始程序语料计划不能拿来执行外部表达，必须准备新计划。

运行模型前，可先只读检查强基线是否还有可测差距：

```bash
python report/analysis/O4_D_RESEARCH_20261024_01/audit_baselines.py \
  --corpus semantic_pallet_planner/outputs/DATA_O4_D_EXTERNAL_EXPRESSIONS_NEW \
  --output /tmp/o4_external_baseline_headroom.json
```

该审计不调用模型；它不按模型表现筛题，也不能用来刻意删除强基线能做对的题。外部表达上的模型增量仍须真实API实验确认。
