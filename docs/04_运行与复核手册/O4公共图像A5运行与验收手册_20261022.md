# O4公共图像A5运行与验收手册

日期：2026-10-22。范围：A5公共图像、箱面事实、一致性及离线附件传输。无需Flash，不调用真实API；A6人工审阅与D模型评估单独进行。

## 环境与入口

从仓库根目录执行，使用项目既有Pillow/jsonschema/PyYAML依赖：

```bash
export PYTHONPATH="$PWD/semantic_pallet_planner/src"
python -m semantic_pallet_planner.runners.o4_visual --help
```

需要`/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`。交付保存字体文件、SHA256及Python/Pillow/zlib版本；缺少字体或环境漂移会明确失败。配置为`semantic_pallet_planner/configs/o4_a5_visual.yaml`，首版配置冻结，修改需新版本。

## 单输入渲染、冒烟与正式验收

```bash
python -m semantic_pallet_planner.runners.o4_visual render \
  --source <无附件公共请求或完整公共缓冲状态JSON> \
  --output /tmp/O4_A5_RENDER_NEW

python -m semantic_pallet_planner.runners.o4_visual smoke \
  --output /tmp/O4_A5_SMOKE_NEW --limit 4

python -m semantic_pallet_planner.runners.o4_visual acceptance \
  --output semantic_pallet_planner/outputs/EXP_O4_A5_VISUAL_REPRO_NEW
```

每次选择新目录，存在目录拒绝覆盖；禁止写入数据集、源码或旧A/B/C/F实验内部。render/smoke至多为PARTIAL，不满足正式全语料A5门槛。

正式语料来自已验收A/B的36个金标准与144条配对请求、C全部1604条决策记录，以及F全部9123个事件的前后公共状态。仅提取公共字段，不把完整私有轨迹传入渲染器。每条原始引用在private/source_references.json可追溯，按完整公共输入摘要去重；图像进一步按公共视觉事实复用。

## 只读回放

```bash
python -m semantic_pallet_planner.runners.o4_visual replay \
  --output semantic_pallet_planner/outputs/EXP_O4_A5_VISUAL_20261022_02

python -m semantic_pallet_planner.runners.o4_visual replay \
  --output semantic_pallet_planner/outputs/EXP_O4_A5_VISUAL_20261022_02 --repeat
```

回放验证旧实验/源码保护、交付文件、字体、全部对象与箱面、绘制文本、实际RGB像素及输入附件绑定；`--repeat`额外逐图重新生成图元和PNG字节。两种回放均只读。正式验收本身已对所有资产执行重复生成。

## 文件阅读和后续接入

- `visual_acceptance.json`：A5正式范围、通过状态及A6/D/E延期。
- `coverage.json`：原始引用、去重输入、资产及类别/yaw/容量覆盖。
- `public/assets/`：场景图、局部卡片、最多六卡一页的标签页。
- `public/assets.json`：资产内容、像素/文件摘要、公开图元与事实；无业务答案。
- `public/requests/`与`public/bundles.json`：每个绑定输入的公共原请求、视觉事实、文本条件和图像条件。
- `image_consistency.json`：全部独立像素/几何校验及逐图重复结果。
- `audit/`：保护、篡改检测、实际PNG传输到测试替身及网络计数。
- `environment/`与`code_snapshot/`：可复核字体和源码环境。

D可调用`o4.visual.bundle.AssetStore.build(public_source)`构造两种条件，按`image_input`/`text_input`获得相同事实。实际模型接口仍需核验附件数量、分辨率、请求预算及响应绑定；A5不提供尚未实现的远程CLI。`offline_transfer`只接受fake客户端，传输的是文件实际PNG字节。

旧A/B/C/F文件不改写。历史C/F回放器的源码清单包含整个包，新增A5模块会触发其原清单的新增文件检测；这与原文件变更不同。历史复核应使用对应冻结源码快照及实际数据路径，不能修改旧manifest以迁就新目录。A5独立核验原manifest记载的全部旧源码与交付哈希。
