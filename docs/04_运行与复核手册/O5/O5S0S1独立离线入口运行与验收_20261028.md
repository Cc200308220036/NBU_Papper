# O5 S0/S1 独立离线入口运行与验收

日期：2026-10-28。依据：[O5开发规范](../../02_阶段实施方案/O5/O5直接VLM基线与自然语言经验沉淀开发及验收规范_20261027.md)。本次 S0/S1 离线工程验收通过，真实 API 调用为 0。D0 采用明确标记的离线替身，结果不构成 VLM 性能证据。

## 1. 独立入口与边界

代码位于 `semantic_pallet_planner/src/semantic_pallet_planner/o5/`，入口为 `semantic_pallet_planner.runners.o5_direct_memory`。复用原 A/E2 物理候选与检查，regions=[]，buffer=1，Top-K≤16，yaw=0/90°，不输入业务 AST，不调用 E5 提交器。容器1200×1000×850 mm、载荷1000 kg，模拟箱均可堆叠、顶部承载100 kg。

G0 使用冻结几何规则；D0 使用公共图文请求、随机显示编号和严格 PLACE/STOP 响应。一次格式修复只附错误码，无正确动作提示、无几何兜底。CLI 的 socket guard 禁止联网；没有真实远程 transport。未实现 R0/M0、未采集训练轨迹、未修改 ReMe vendor、共享评分、旧默认 A 或历史实验。

## 2. 来源审计与批准后的规则

原始 BED-BPP 10003单，14—20箱完整订单676单，SHA-256为 `6ecc91d92b9ce88de113ac66c45a450ac3eec303018f14cd73e4bd0eaf8eb3cc`。按来源别名、完整有序及旋转归一几何/质量多重集、12箱窗口及其多重集聚类，并排除实际 V1 较短窗口、已暴露与 O4-D 预留来源。未解析引用记为 UNKNOWN，不进入可用来源；不声称排除了模型预训练暴露。

最初 >3 长宽比草案不足20个 OOD 簇，01/02号 BLOCKED_DATA 原件保留。用户已明确批准“允许按几何特征分位数定义 OOD，先冻结规则再抽样”，授权见审计目录 `authorization.quantile.json`。

新数据设计 `o5_complete_orders_quantile_v1`：353个可用簇的代表订单，按最大箱体平面长宽比排序，nearest-rank q80，rank=ceil(353×0.8)=283，阈值2.0344827586206895；严格大于为OOD，全部36个阈值并列归ID，形成291 ID/62 OOD池。先生成独立规则计划及封印，再按seed=20261028抽样；不根据装载结果调规则。

正式数据 `outputs/DATA_O5_DIRECT_MEMORY_20261028_03` 已通过：train60/development20/test_id40/test_geometry_ood20，140独立来源簇、2519个原始完整到货箱。逐单与原始数据核对、簇隔离及只读评估文件检查通过。训练集只形成任务定义，没有运行轨迹；运行入口仅允许开发集。

## 3. 可执行命令

从仓库根目录执行。当前环境可直接导入包；更换环境时先配置包路径及依赖。输出目录必须使用新名称，禁止覆盖。

现有正式数据已冻结；下面运行示例直接使用该数据，保持同一研究划分：

```bash
python3 -B -m semantic_pallet_planner.runners.o5_direct_memory prepare \
  --dataset semantic_pallet_planner/outputs/DATA_O5_DIRECT_MEMORY_20261028_03 \
  --output semantic_pallet_planner/outputs/PLAN_O5_DIRECT_MEMORY_MY_DEV --count 2

python3 -B -m semantic_pallet_planner.runners.o5_direct_memory run \
  --plan semantic_pallet_planner/outputs/PLAN_O5_DIRECT_MEMORY_MY_DEV \
  --output semantic_pallet_planner/outputs/EXP_O5_DIRECT_MEMORY_MY_DEV \
  --max-jobs 1 --stop-after 3

python3 -B -m semantic_pallet_planner.runners.o5_direct_memory run \
  --plan semantic_pallet_planner/outputs/PLAN_O5_DIRECT_MEMORY_MY_DEV \
  --output semantic_pallet_planner/outputs/EXP_O5_DIRECT_MEMORY_MY_DEV --resume

python3 -B -m semantic_pallet_planner.runners.o5_direct_memory verify \
  --experiment semantic_pallet_planner/outputs/EXP_O5_DIRECT_MEMORY_MY_DEV

python3 -B -m semantic_pallet_planner.runners.o5_direct_memory report \
  --experiment semantic_pallet_planner/outputs/EXP_O5_DIRECT_MEMORY_MY_DEV \
  --output report/analysis/O5_MY_DEV_REPLAY

python3 -B -m semantic_pallet_planner.runners.o5_direct_memory pilot-draft \
  --dataset semantic_pallet_planner/outputs/DATA_O5_DIRECT_MEMORY_20261028_03 \
  --output semantic_pallet_planner/outputs/PLAN_O5_DIRECT_MEMORY_MY_S2_DRAFT
```

来源派生的执行顺序如下。它用于复核本次初始来源审计，不代表未来可以忽略新增暴露重新抽取“未见”数据；后续研究继续使用已经冻结的03号数据。

```bash
python3 -B -m semantic_pallet_planner.runners.o5_direct_memory freeze-data-rule \
  --audit-data semantic_pallet_planner/outputs/DATA_O5_DIRECT_MEMORY_20261028_02 \
  --output semantic_pallet_planner/outputs/PLAN_O5_DIRECT_MEMORY_MY_RULE
python3 -B -m semantic_pallet_planner.runners.o5_direct_memory prepare-data \
  --rule-plan semantic_pallet_planner/outputs/PLAN_O5_DIRECT_MEMORY_MY_RULE \
  --output semantic_pallet_planner/outputs/DATA_O5_DIRECT_MEMORY_MY_DATA
```

`prepare-data`必须持有冻结规则，重新审计的来源总体与其不一致时保留诊断并拒绝抽样。`prepare-fixture --output <新PLAN目录>`可生成明确合成的14/20箱协议夹具，不进入正式数据或经验库。

## 5. 账本、恢复与测试

## 6. ReMe与S2交接

ReMe本地声明0.4.1.11，当前解释器未安装reme-ai/agentscope；只做静态接口核实，无服务初始化。实际为Application.run_job、Agent型auto_memory、auto_dream提取与逐单元整理以及BM25；没有同名ingest/consolidate/freeze/snapshot接口。默认后台/cron、多轮Agent及内部重试必须在S3独立限制和记账。本轮不实现经验生命周期，E08—E10延期S3。

S2草案为 `outputs/PLAN_O5_DIRECT_MEMORY_S2_DRAFT_20261028_04/pilot_draft.json`：已绑定开发集前8个完整订单，最多290次选择尝试（含每次最多一次格式修复），不超过320全局上限。模型、provider、版本、价格、金额限额、真实PNG传输和seed能力未冻结，保持 `DRAFT_NOT_EXECUTABLE / COST_NOT_FROZEN`。E13仅通过离线真实PNG编码检查，真实provider预检属于S2；本轮授权不包含真实API。
