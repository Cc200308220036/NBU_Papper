## 两次区域违规的同状态诊断

仅在已保存状态上，调用公开业务评分器评价原有物理池，不再调用模型、不模拟未来、不修改已保存选择。成本二元组为（新增违规事件数，动作后违规实例数）。

- `J0004_D0001`：Jev所选成本[1, 1]，同状态最低成本[0, 0]；48个候选中有42个不会新增违规。同一箱体的最低成本为[0, 0]。
- `J0004_D0009`：Jev所选成本[1, 2]，同状态最低成本[0, 1]；32个候选中有16个不会新增违规。同一箱体的最低成本为[1, 2]。

第2次放置时，同一箱已有不新增违规的位置；这是当前候选内可避免的区域违规。第10次放置时，该箱所有保留候选都会新增违规，但选择另一箱可以暂不新增违规。后者不能直接证明换箱后能完成更多或整单更优；需要另行开展开发集反事实验证。

这些观测说明本轮同时存在局部业务选择问题与后续空间受阻。B1中Jev比业务启发式多放1箱且无违规；B2中两者都放12箱，Jev新增违规更多。不能据两个同源任务宣布Jev总体胜出。B1/B2只算一个独立来源，也没有完整业务可满足性见证。
