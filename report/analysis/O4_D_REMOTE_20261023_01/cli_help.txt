usage: o4_remote.py [-h] {prepare,run,replay} ...

O4-D frozen plans, explicit remote calls, offline checks and read-only replay.

positional arguments:
  {prepare,run,replay}
    prepare             freeze inputs/model/prompts before any API calls
    run                 execute a frozen plan in a NEW directory
    replay              read-only; no keys or network required

options:
  -h, --help            show this help message and exit
