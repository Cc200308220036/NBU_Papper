## 页面功能

- 两条真实轨迹逐步回放、初始/终态/首分歧跳转，轴测/俯视与拖动同步旋转。
- 实际已放箱与可选的假设候选分开显示，候选位置、支撑率与中心裕量可查；假设候选不代表实际提交。
- 完整公共决策JSON、保存响应、实际HTTP文本请求体、服务响应文本及usage可查。内部候选审计单独标为事后审计，不冒充模型输入。
- 逐决策实际位置及全部8单的背景结果。17箱分母属事后评价，未来明细不输入模型。

模型响应未要求自然语言理由，故页面不生成或推断模型思维过程。仿真物理规则仍为原70%支撑率、几何中心与合成承重等，未验证真实摩擦、纸箱变形、组合重心或搬运稳定性。通过旧物理检查不等于真实场景稳定。
