# O5 OOD 划分待审方案

状态：仅供审查，尚未应用，不改变当前 `BLOCKED_DATA`，不生成正式来源划分。

上位 O5 规范要求在任何模型结果出现前，根据外生几何特征冻结 ID/OOD 划分，但未指定数值阈值。本轮初步草案“最大箱体平面长宽比>3”只得到4个可用来源簇，不足20个。完整审计后的可用来源簇总数为353，问题在于当前分层规则，不是总来源不足。

建议审查如下确定性规则：

1. 每个可用来源簇按已记录种子 `20261028` 的哈希排序取一个代表完整订单，保持现有排除和聚类结果。
2. 特征为订单内各箱 `max(length,width)/min(length,width)` 的最大值。
3. 对353个代表的特征排序，采用 nearest-rank 第80百分位：`ceil(0.8×353)=283`，取第283个值作为阈值，即 `2.0344827586206895`。
4. ID 池取小于等于阈值的来源簇，OOD 池严格大于阈值；阈值处36个同值来源簇全部留在 ID，避免把相同几何值人为拆到两侧。
5. 实际得到 ID 池291簇、OOD池62簇，足以按原配额选择60训练、20开发、40 ID测试和20 OOD测试。池内仍使用既定种子和哈希次序，不依赖 G0/D0 成败。

该方案只调整待冻结的数据分层定义，保持总量140、完整14—20箱、原A/E2候选、模型权限和现有费用边界。原 `>3` 草案及两份阻塞产物保留。尚未选出任何正式训练/测试任务，不运行任何新模型或规划。

批准后仍须发布数据设计修订记录，生成新目录，验证来源隔离和完整原始到货序列，再建立开发离线计划及完整 S2 草案。若不批准，保留当前规则与阻塞状态。这里的几何可分性不证明模型收益、工业独立采集或统计功效。

机器可读输入摘要、计算方法和数量见 [ood_rule_proposal.json](ood_rule_proposal.json)；没有按任何测试结果挑选阈值。
