# JM1-C2 分叉决策对比

直接用浏览器打开 `web/index.html`，无需联网或安装依赖。转交时发送完整web目录，或使用本目录的离线包ZIP；不要单独复制HTML。

建议阅读顺序：P01 → 首步动作差异 → 完整后缀 → 点两次“下一次放箱” → 输入/输出 → 最终效果 → 重复比较。P02为负例，P03为中性，P04未登记重复，P05说明相同件数下箱体组成和装入体积变化。

## 页面内容

- 共同输入：保存前状态、当前缓冲、完整公开候选和父决策概率。父决策概率与C2新选择明确区分。
- 首步差异：坐标/尺寸/朝向差、3D叠加、真实坐标俯视放大、冻结首步的保存监测与提交。
- 完整后缀：双时间线、独立游标、同步按新增放箱数浏览、连续播放、候选预览；输入、输出、监测与提交、证据四页签。请求正文、响应原文、概率、精确动作、usage、来源及JSON下载可展开。
- 最终效果：参考/替代终态3D、俯视、主要指标、全部保存差值、箱体集合与布局差异、终态缓冲、停止原因和成本状态。
- 重复比较：r0/r1 × 参考/替代四格、每次配对差和同分支动作序列；P01高度方向冲突、P04未登记重复均明确保留。
- 证据：完整分母、来源组件、材料准入边界和来源摘要。没有生成新的T/E。

## 身份与研究边界

保存数据为5个起点、18条运行、9组比较，57次请求、18强制首步、75次新增提交、168个完整事件、450阶段文件。终态装入数包含共同前缀，新增提交单独计数。4改善/3退化/2中性仅为局部观察；全部空物理候选池停止、整单完成0。费用UNKNOWN；3个保守来源组件，未见独立来源0，覆盖PARTIAL。

“既定后缀”固定任务和后续策略，不固定后续随机动作。仅原动作参考＋相同无经验Jev后续参与收益比较。两次一致不能证明泛化，P01不能称全面稳定改善，中性不等于相同布局。未选动作无PCT结果。包装承载为合成属性；空池不等于全局无解。

页面只读归档，未调用模型、生产候选器、订单引擎或静态内核；未读取凭证，未修改历史数据和生产源码。复用旧JN4的本地Three.js及OrbitControls，许可证见web/vendor/。
