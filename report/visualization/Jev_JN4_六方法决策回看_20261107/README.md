建议先看默认的第3单，再切换六个方法：

1. **逐步回看**：时间线 / ← → / 连续播放浏览每个保存的决策节点。切换选择前、候选预览、监测后、提交后；拖动3D视图、缩放、点击箱体。
2. **候选与评分**：列出该步所有展示候选，显示原始Jev概率、几何启发分、位置、支撑比例和实际选择。最高概率并列会在摘要、候选行、方法卡及时间线上标注，可上一/下一并列跳转。可排序、筛选、点击预览其他候选；未展示物理候选与生成拒绝计数另行折叠。
3. **本步经验**：实际请求正文内的T历史案例、E对比经验或无关E文字；同时查看相关度、资格和长度截取。未知发送的正文仅证明准备/发送记录，不能确认服务处理。
4. **PCT检测与计算**：仅对实际选中动作展示检测结果、精确位置、接触网络、支承反力、质量/力矩残差、守恒、容差。可切换箱体节点，在3D中显示反力方向；箭头长度是展示缩放。
5. **六方法对照**：六条轨迹最终布局并排，或按决策序号浏览，附保存的同版本配对评价。序号相同不意味着同状态/同候选池。
6. **经验档案 / 证据与边界**：查看冻结的2条T、2条E及事实出处；新增T/E最高概率并列统计（默认第3—6单同v3，可切全范围）以及经验来源决策的历史概率对照；核对完整36槽位、算法版本、源码身份、所属run、请求与成本。每步可查看请求/响应原文和JSON定位，并下载该步JSON。
