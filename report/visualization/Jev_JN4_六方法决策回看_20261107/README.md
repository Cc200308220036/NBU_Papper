# JN4 六方法决策回看

用 Chrome / Edge 打开 **web/index.html**。不需要安装依赖、启动模型或连接网络。转交他人时请发送整个离线ZIP包，解压后打开 web/index.html；不要只复制一个HTML文件。

建议先看默认的第3单，再切换六个方法：

1. **逐步回看**：时间线 / ← → / 连续播放浏览每个保存的决策节点。切换选择前、候选预览、监测后、提交后；拖动3D视图、缩放、点击箱体。
2. **候选与评分**：列出该步所有展示候选，显示原始Jev概率、几何启发分、位置、支撑比例和实际选择。最高概率并列会在摘要、候选行、方法卡及时间线上标注，可上一/下一并列跳转。可排序、筛选、点击预览其他候选；未展示物理候选与生成拒绝计数另行折叠。
3. **本步经验**：实际请求正文内的T历史案例、E对比经验或无关E文字；同时查看相关度、资格和长度截取。未知发送的正文仅证明准备/发送记录，不能确认服务处理。
4. **PCT检测与计算**：仅对实际选中动作展示检测结果、精确位置、接触网络、支承反力、质量/力矩残差、守恒、容差。可切换箱体节点，在3D中显示反力方向；箭头长度是展示缩放。
5. **六方法对照**：六条轨迹最终布局并排，或按决策序号浏览，附保存的同版本配对评价。序号相同不意味着同状态/同候选池。
6. **经验档案 / 证据与边界**：查看冻结的2条T、2条E及事实出处；新增T/E最高概率并列统计（默认第3—6单同v3，可切全范围）以及经验来源决策的历史概率对照；核对完整36槽位、算法版本、源码身份、所属run、请求与成本。每步可查看请求/响应原文和JSON定位，并下载该步JSON。

模型未保存自然语言推理，因此页面只呈现规则、实际输入、实际概率与实际选择，不编造“Jev为什么选它”。本地/单候选/未收到响应没有模型概率，标NA；概率不是PCT分数。未选候选没有PCT结果。中文经验说明是展示层释义，英文公开片段是实际输入。三维视图仅根据保存位置绘制，不做物理回放或新求解。

- 累计预约412/656；已知调用411、未知1，实际调用UNKNOWN / [411,412]；费用UNKNOWN。

## 最高概率并列的两层对照

按服务保存的原始数值精确相等判断，不按显示百分比舍入，不使用容差合并。仅有原始概率的真实Jev决策进入分母。

| 范围 | 无经验 | T案例 | E经验 | 无关E |
|---|---|---|---|---|
| 全36槽位（跨版本台账） | 13/117 | 7/105 | 8/100 | 9/89 |
| 第3—6单（同v3） | 8/85 | 6/73 | 5/66 | 7/67 |

数字为“最高并列次数 / 有概率决策次数”。它们是各自实际轨迹的描述，状态/候选池/步数不同，不能当作经验减少不确定性的因果证据。

T-1/E-1共同来源F00，T-2/E-2共同来源F02，只有2个不同历史决策。核对分叉快照的完整原始概率与父决策记录一致：F00的C14=0.29唯一最高，F02的C18=0.29唯一最高；两者均有较低概率相同项。分叉后续采用本地几何策略，不产生新的Jev概率。“经验来源是否有最高并列”与“使用经验后是否有最高并列”在页面分开呈现。

`probability_tie_audit.json`保存全部411个有概率决策的并列分组、37个最高并列定位及两条历史原始概率和来源摘要。本步实际T/E经验也可直接查看其历史最高值。未知响应/本地/singleton不计入该分母；服务打破并列的规则仍为UNKNOWN。

## 文件与复核

- `web/`：独立页面、按job懒加载的数据和仓库既有Three.js资源（许可证在vendor内）。
- `build_data.py`：标准库导出器，从最终checkpoint和已保存账本提取数据，不读取前缀检查点或执行订单。
- `source_manifest.json`：全部读取来源的SHA-256；`export_receipt.json`：导出范围与计数。
- `arithmetic_audit.json`：5,531个节点对保存反力的加减核对，0项越过保存容差；没有调用LP求解器。
- `qa/browser_checks.json`：浏览器实测；`qa/*.png`：桌面、手机、候选、PCT及六方法截图。
- `manifest.json`、`handoff.json`：本展示交付的文件身份与范围。


然后访问 http://127.0.0.1:8767 。服务器只提供文件，不调用模型。关闭后页面也可继续离线使用。
