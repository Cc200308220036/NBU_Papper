# SCN_0054 / P1：从11箱到17箱的逐步3D回放

这是已有V2真实实验的离线可视化。展示原策略、预算＋几何、预算＋布局三种策略，分别覆盖安全模式和业务观察模式，共6条真实轨迹、91条事件。没有调用模型、重新规划或修改原实验。

## 打开与使用

直接用桌面版Chrome、Edge或其他支持WebGL的浏览器打开 [index.html](index.html)。轨迹数据和Plotly引擎均已嵌入HTML，单独复制HTML也能离线回放；建议解压完整资料包后打开，以保留CSV、JSON、截图及来源附件。

- 上一步 / 下一步、滑块、左右键：按到货序号查看0—17箱。空格播放或暂停。
- 默认在关键步暂停。点击关键节点可跳到第5、6、8、12、16、17箱。
- 选择安全 / 业务观察模式，对照业务拒放和允许违规继续的不同后果。
- 鼠标拖动旋转，滚轮缩放；默认同步三幅视角，可切俯视、侧视或立体。
- 切“放置前＋选择位置”，绿色线框表示本步实际选址；打开候选中心后，可点击点或使用下拉框检查候选，紫色线框表示检查中的位置。
- 选中的候选仅属于本方法本次请求，不能跨方法用Cxx判断是否同一位置。
- 悬停箱体可查看尺寸、质量、易碎、品类、承载与可堆叠性。展开“布局指标与本步依据”可查看候选评价、软预算损失、原始请求绑定及拒绝原因。
- “保存视图”下载该策略当前3D视图的PNG，可用于后续汇报。

## 推荐讲解顺序

| 节点 | 实际发生的事情 | 讲解重点 |
|---|---|---|
| 第0—4箱 | 三策略布局一致 | 同状态、同候选器的比较起点 |
| 第5箱 | 布局方案与另两方案首次分叉，选择位置和yaw不同 | 最新V2布局分叉发生于第5箱；此时没有已放重箱，软目标为N/A，不应归因为牺牲重箱目标 |
| 第6箱 | 原策略第6箱底面160mm，另两策略仍放地面 | 原策略与几何预算控制首次分叉；三个选择当时均无业务违规 |
| 第8箱 | 原策略当前箱底面410mm；几何控制160mm；布局250mm | 顶面、支撑与高度差异开始累积，不能仅看空地面积 |
| 第12箱 | 原策略1192枚举位姿，越界658、碰撞464、支撑不足70，返回0候选 | 原策略停在11/17箱；该步扩大Top-K无法产生候选，仍非全局无解证明 |
| 第16箱 · 安全模式 | 几何控制返回16个物理候选，业务可行0，停于15/17 | 物理可放与业务可放是两层约束；零违规不能代替完整完成 |
| 第16箱 · 观察模式 | 几何控制继续放，引入箱09与箱16禁止接触违规 | 观察协议允许业务损害，保留物理检查；红连线只是关系，不是接触面积 |
| 第17箱 | 布局方案17/17且最终0违规；几何观察方案17/17且最终2违规 | 同样完成不代表相同合规；单个案例也不能证明总体泛化 |

## 证据和边界

来源实验：`semantic_pallet_planner/outputs/EXP_OPT_O3_LAYOUT_FLASH_V2_VALIDATION_20261020_01`，场景`SCN_0054`，政策`P1`。

- 每个模式每个策略使用独立的真实闭环状态，停止后明确显示冻结布局，没有伪造后续动作或候选。
- 逐步核对了对应Flash轨迹的前后状态哈希、实际位姿、提议、提交和终止均与Parser一致，因此页面合并展示一致轨迹。
- 本案例的空间收益来自共同执行器和布局策略，不构成Flash优于Parser、视觉或动态经验记忆的证据。
- 旧失败归因里“第6箱分叉”比较的是原Parser与Geometry基线。这里比较最新V2三变体，预算＋布局与原策略在第5箱分叉，预算＋几何与原策略在第6箱分叉；两种比较不能混同。
- 业务硬规则包括易碎3kg限载和禁止接触，软目标先居中再低位。预算变体的归一化允许损失为居中0.25、低位0.05；它们不修改物理硬约束。
- 物理承载上限、品类、易碎等属性包含合成值；此处不是机器人实测。
- 垛高曲线在终止后仅以虚线延伸表示冻结布局；业务候选曲线不伪造停止后的候选。
- 同批整体只有10个已见来源订单，仍需独立验证。SCN_0060中布局策略只放7/17，预算几何能放16/17，二者均未完成，应作为本案例之后的负例保留。
