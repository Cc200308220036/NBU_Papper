# Jev真实案例3D观察页

直接用支持WebGL的浏览器打开index.html；所有资源与数据已内嵌，无需API密钥、网络或后端。也可在此目录运行python -m http.server 8766 --bind 127.0.0.1，通过http://127.0.0.1:8766查看。

案例SCN_0065_B1，J0025，13次真实Choice。逐步播放、每步全部候选、三维预览、真实输入输出和执行后业务评价均来自封存记录。

Jev没有返回选择理由；页面的解释是标明来源的事实比较与事后分析，不能当作模型自述。备选未做反事实执行。落箱动画为图示，只有起止坐标来自记录，不代表机械臂运动路径。

模型本轮只见当前状态。页面订单总数、未来步骤和最终结果是离线审计信息，不会反向送给模型。本页没有新增API调用、候选生成、仿真或轨迹重执行。
