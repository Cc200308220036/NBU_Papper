## 设计、物理约束与语义差异

先写[设计说明](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/stability/BALANCE_DESIGN.md)，再实现独立模块；设计的开发修订及失败证据保留。[语义变更说明](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/stability/BALANCE_CHANGES.md)明确列出与上游的差异，不冒称未经修改的PCT算法。

复用已有 BoxInput/PlacedState、实际质量→密度、毫米/公斤、0/90旋转、中心/角点、重心/顶点和精确原落高核对。真实调用原 Space.drop_box 构建接触，保留交集6位舍入、x+=y×1e-6微扰和凸包向顶点均值收缩10%。不修改原下载或vendor算法文件，不改几何来迁就案例。

选择**全接触网络竖直静力平衡**，不是逐节点贪心分流。每个正面积水平接触矩形的四个实际顶点各设非负反力，单位为kg等效竖直力（共同重力加速度约去）。顶点组合能表达整个接触矩形内的作用点，而非只允许支撑中心。地面反力作用在地面箱实际足迹顶点。对每箱同时施加：

```text
出流质量 − 入流质量 = 箱自身质量
出流 x 水平力矩 − 入流 x 水平力矩 = 自重 × 自身重心 x
出流 y 水平力矩 − 入流 y 水平力矩 = 自重 × 自身重心 y
每个接触反力 >= 0
```

每个接触力在上/下箱方程中各出现一次、符号相反，整张网络同时求解，完成后统一审计；不先递归更新单个祖先，避免共享祖先漏计、双计和暂态判断。真实箱体提交顺序不变，求解器行/列仅按ID、接触对象和顶点坐标规范排序。每候选新建Space、按真实顺序逐箱恢复并检查每个前缀；没有跨候选缓存或原状态写回。

原收缩/微扰凸包作为非地面箱组合反力中心的额外保守条件保留，物理接触顶点本身不收缩、不移动。单支撑、双支撑、直接支撑与多支撑全部经过同一方程组，旧 impact 快捷分支不执行。虚拟drop/check、setting=2、自动旋转flag显式拒绝。原包装C、stackable、面积分载与载荷账本不参与求解、不改写；它们仍由原物理准入负责。

## 求解、确定性与结果分类

以总自身质量T归一化反力，以容器水平最大尺寸L归一化力矩，各箱力矩方程以其自身重心为原点。实际提交图是DAG，每个归一化反力的有效界为[0,1]。

先检查完整物理接触网络可行性，再最大化反力与原保守凸包的共同内部余量t，冻结t后按规范化列顺序逐个最小化反力并冻结各最优值。多解由这个明确的词典序规则确定，不要求重现某一唯一分流份额。使用 SciPy 1.15.3/HiGHS dual simplex，presolve=False，所有阶段相同设置、没有静默重试或换算法。

数值合同冻结：高度1e-6 mm；质量atol=1e-9 kg、rtol=1e-9；水平力矩atol=1e-6 kg·mm、rtol=1e-9；求解器可行性1e-10；无量纲残差1e-9；严格内部余量阈值1e-10；不可行分离间隙阈值1e-8。实际容差及局部/全局残差随结果保存。没有负值裁剪、事后归一化、软守恒替代、改符号补丁或放宽容差。

- **STABLE**：得到有限、非负、局部/全局质量与两个水平力矩守恒、满足保留凸包和严格内部选择条件的全网络解。
- **UNSTABLE**：完整物理网络不可行，且存在独立复核通过的有界Farkas分离证书。仅求解器报infeasible不够。对 `A f=b, 0<=f<=1`，检查证书y给出的 `b·y < sum(min(Aᵀy,0))`，间隙须超过冻结阈值；这里取负部分用于证书界，不是裁剪反力。
- **UNASSESSABLE**：物理可行但收缩凸包不满足、只能认证边界/零反力解、不可行没有有效证书、退化/范围外或落高不符。不能从局部一次分流失败推导全局失稳。
- **ERROR**：求解异常/非收敛、非有限、负反力或守恒残差失败。不会作为稳定或物理失稳。

前缀失稳独立返回UNASSESSABLE/BASELINE_UNSTABLE；前缀错误独立保留。结果区分 `geometry_precheck` 与 `post_drop_network`，几何预检失败不携带前缀反力冒充候选结果。无法可靠定位失稳对象仍为null。
