## 实现与恢复合同

新增实现集中于 [stability/monitor.py](../../../semantic_pallet_planner/src/semantic_pallet_planner/jev_select/stability/monitor.py)、`metrics.py`、`runtime.py`。复用现有 `episode.py`、候选/上下文、`commit_physical`、原子 `ledger.write` 和排他锁，没有平行订单运行器。独立协议 **jev_packaging_monitored_v5** 配套config/candidate/context/selection/checkpoint与指标Schema；旧v4 Schema字节未变，不接受监测扩展字段。

唯一开关为 `stability_monitor.enabled`，默认false。CLI on/off与 `--monitor-config` 的布尔值归一到同一字段，显式冲突报错；其余算法参数取冻结资源。关闭时不导入/调用PCT、v2或SciPy，记录DISABLED且检测次数0。独立子进程阻断这些导入，确认新关闭路径与旧v4动作、最终状态一致；开启/关闭同一公共状态下的候选内容、顺序、编号、选择body一致。

共享调度顺序为：选定精确动作 → SELECTED原子检查点 → 独立副本真实v2评价 → MONITORED原子检查点 → 凭证复核 → 原物理提交 → COMMITTED原子检查点 → 下游评价。单候选与本地方法走同一入口；通用选择接口保留，真实远程/非空经验仍拒绝。结果不进入候选、选择body或后续公共上下文；PCT反力与原面积分载/C账本分离。

STABLE提交一次；UNSTABLE保留attempted动作，箱体留在缓冲，结束为PREDICTED_STATIC_INSTABILITY；UNASSESSABLE与ERROR分别结束为STABILITY_UNASSESSABLE、STABILITY_MONITOR_ERROR，不算预测失稳。前缀失稳仍为BASELINE_UNSTABLE；原提交失败保持COMMIT_FAILURE与独立指标类别。

恢复使用同一原子检查点内的状态及提交阶段。SELECTED复用原动作，不重新生成候选或选择；MONITORED校验并复用已存结果；COMMITTED只接续下游评价；TERMINATED不执行后缀。验证历史提交时在私有副本上调用原物理检查进行纯重建，不再次派发真实运行提交；累计载荷与正式状态不双计。提交后、COMMITTED写盘前中断时只有内存返回值，旧MONITORED仍为唯一持久状态；写盘后恢复其已提交状态。临时`.atomic-*`不作为检查点读取。

凭证绑定完整状态、候选、精确动作、选择、上下文/原物理池、配置、数据/物理/策略/监测/任务/决策身份及结果摘要。凭证的`committed=false`表示评价本身尚未提交；真实提交以PLACE/action/after及COMMITTED为准。已保存结果不得覆盖，阶段记录与最终动作逐项比对。恢复测试覆盖5种阶段、重复恢复、MONITORED预测停单和身份篡改；外层检查点重算摘要仍不能掩盖内部绑定篡改。

## 使用与产物

仓库根目录，选择满足工程要求的Python：

```bash
export PYTHONPATH="$PWD/semantic_pallet_planner/src"
python -m semantic_pallet_planner.jev_select smoke-packaging-monitor \
  --dataset semantic_pallet_planner/outputs/DATA_JEV_PACKAGING_LOAD_20261102_02 \
  --stability-monitor on --output semantic_pallet_planner/outputs/NEW_MONITOR_ON
# 关闭：同一命令使用 --stability-monitor off 和另一个全新输出目录。
# --event-limit N 可限制到1—8事件；默认8，不支持全单矩阵。
python -m semantic_pallet_planner.jev_select validate-stability-report \
  --report semantic_pallet_planner/outputs/VERIFY_JEV_PCT_MONITOR_20261103_01/smoke_on
```
