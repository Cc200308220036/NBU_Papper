HOW TO READ
看过程，也看证据。
  1. 每一个时间点对应一次真实 Jev 调用：先看执行前状态，再查看候选，最后看实际提交结果。
  2. Cxx 是一个“选哪箱 + 放哪里 + 朝向”的完整动作编号，不是箱号；每一步重新编号。
  3. 候选空间显示全部物理候选，列表可按概率或几何分排序。点击备选只改变预览，不会替换真实动作。
  4. “选择解释”展示可观测证据；Jev 没有输出理由或思维链，页面不会假造其动机。
  5. 业务违规由执行后的独立评价记录。违规不会终止此订单，但不代表所有候选都有合规替代。
  6. 订单总件数与最终结果是离线审计信息；Jev 每步只看到当时到货箱体。memories 始终为空。
